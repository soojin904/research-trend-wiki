## 초록

Abstract The World Wide Web has evolved from a predominantly static information environment into an increasingly interactive, semantic, distributed and intelligent digital ecosystem. The earlier study on Web 1.0 to Web 3.0 described the transition from the read-only web to the read-write social web and then toward the semantic web. This revised study extends that framework to Web 4.0 and examines the technological and conceptual changes across the four stages. Web 1.0 is characterized by static pages, one-way information delivery and limited user participation; Web 2.0 emphasizes interaction, user-generated content, social networking and web applications; Web 3.0 is associated with semantic interoperability, decentralized architectures, data ownership and intelligent processing; and Web 4.0 is increasingly discussed as an intelligent or symbiotic web in which artificial intelligence, Internet of Things (IoT), cloud/edge computing, augmented and virtual reality, machine-to-machine communication and autonomous agents can interact with people and each other. The literature does not provide one universally accepted definition of Web 4.0, so this paper treats it as an emerging research and technology paradigm rather than a fixed technical standard. The study also discusses implications for libraries and information services, including intelligent discovery, personalized services, virtual assistance, semantic knowledge organization and human-machine collaboration. The paper concludes that the movement from Web 1.0 to Web 4.0 represents a shift from information access toward participation, meaning, intelligence and increasingly symbiotic interaction.
