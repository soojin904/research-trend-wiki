# 감성 분석 (Sentiment Analysis)

텍스트에서 감정·태도·의견의 극성(긍정/부정/중립) 또는 세부 감정(기쁨·분노 등)을 자동 추출하는 방법론.

> **2026-09-22 갱신**: `pages/papers/applied/` **789편 전수 판독** 기준 **~213편(~27%)**. LLM/생성형 AI(~215편)와 사실상 공동 1위로, 이전 682편 집계의 "1위" 판정이 **더 큰 표본에서도 대규모 클러스터임이 재확인**되었다(비율은 37%→27%로 조정 — 이전 추정이 다소 과대). 7개 청크 전부에서 25~35편씩 고르게 분포해 **특정 연도·도메인 유행이 아닌 구조적 주류 방법론**임이 확인된다.
> 근거: [[pages/insights/applied_method_frequency_2026|응용 분야 방법론 빈도 (2026, 789편)]]

**세대 공존이 특징**: 사전 기반 → 전통 ML → 트랜스포머 → LLM의 네 세대가 동시에 사용되고 있다. 신규 방법이 구 방법을 축출하지 않고 누적되는 구조.

## 핵심 개념

### 분석 유형

| 유형 | 설명 | 주요 도구 |
|------|------|-----------|
| **문서/문장 수준** | 전체 리뷰·게시글의 긍/부정 분류 | BERT, VADER, TextBlob |
| **측면 기반 (ABSA)** | 특정 속성(가격·직원 친절·배송 등)별 감성 | BERTopic+ABSA, aspect-level BERT |
| **감정 다중 분류** | 기쁨·분노·슬픔·신뢰 등 세부 감정 레이블 | RoBERTa, XGBoost+SHAP |
| **비교 감성 분석** | 두 대상(제품·후보) 간 감성 비교 | LLM 벤치마킹 |

### 주요 도구 및 편수 (682편 기준)

| 도구 | 유형 | 편수 | 특징 |
|------|------|------|------|
| **BERT / RoBERTa / 계열** | 딥러닝 | ~140 | 맥락 이해 강점, 파인튜닝 필요 |
| **VADER** | 사전 기반 | ~35 | 소셜미디어 단문에 최적화, 코딩 불필요 |
| **TextBlob** | 사전 기반 | ~25 | 간편한 영어 감성, 낮은 정확도 |
| **SVM + TF-IDF** | 전통 ML | ~40 | 여전히 표준 베이스라인, 해석 용이 |
| **앙상블/하이브리드** | 혼합 | ~28 | VADER+BERT, TF-IDF+SVM, 다방법 앙상블 |
| **IndoBERT / AraBERT / mBERT 계열** | 다국어 | ~25 | 저자원 언어 특화 모델 급증 |
| **ABSA (측면 기반)** | 딥러닝+규칙 | ~25 | SBERT+ABSA, aspect-level BERT 등 |
| **감정 다중분류** | 딥러닝 | ~12 | NRCLex·Plutchik 기반 11개+ 감정 범주 |

## 실제 사용 패턴 (응용 분야 논문 기반)

### 데이터 소스별 패턴

| 데이터 소스 | 감성 분석 목적 | 대표 논문 맥락 |
|------------|--------------|----------------|
| **Twitter/X** | 정책·사건에 대한 여론 감성 | 인도네시아 정책 반응, 선거 여론 |
| **리뷰 플랫폼** (Amazon, Google Play) | 제품·서비스 만족도 측면 분석 | 피트니스 센터 리뷰, 앱 스토어 리뷰 |
| **Facebook 댓글** | 뉴스 기사·방송 반응 | Al Jazeera·BBC 아랍어 페이지 287,796개 댓글 |
| **YouTube 댓글** | 동영상 컨텐츠 반응 | 교육 콘텐츠, 광고 반응 |
| **뉴스 기사** | 미디어 프레임·담론 감성 | 코로나 관련 언론 보도 |

### 방법론 결합 패턴

- **감성 + 토픽모델링** (~30편): 소비자 리뷰에서 "어떤 주제에서 어떤 감성인가" 동시 파악
  - 예: LDA 토픽 추출 → TextBlob/VADER 감성 레이블링 → XGBoost 예측 + SHAP 설명 (Alcántara Alcover 2026)
- **감성 + SNA** (~10편): 소셜미디어 감성 노드·엣지로 구성해 의견 확산 네트워크 분석
- **감성 + LLM 자동 코딩** (~20편): GPT/BERT로 대규모 텍스트 자동 감성 레이블링

## 측면 기반 감성 분석 (ABSA) 심화

ABSA는 단순 긍/부정을 넘어 **속성별 감성**을 추출. 응용 분야에서 마케팅·서비스 분야의 표준 분석으로 자리잡는 중.

```
입력: "배송은 빠른데 포장이 엉망이다"
→ [배송: 긍정] [포장: 부정]
```

**주요 방법**:
- BERTopic + IndoBERTweet 결합 (Adam 2026)
- Aspect-level BERT (SemEval 데이터셋 벤치마킹)
- **서비스 속성 식별 → 감성 분류 → SHAP 해석** 3단계 파이프라인이 표준화

### ⭐ ABSA-via-LLM이 토픽모델링을 대체한다 (789편 신규 발견)

> 근거: 청크 3의 직접 비교 연구

LDA로 문서를 **단일 토픽에 할당**하는 방식은 **정보 손실이 51.2%**에 달하며, GPT 기반 ABSA가 문서 수준 토픽모델링을 현저히 능가한다는 정량 비교 결과가 확인되었다.

| | 문서 수준 토픽모델링 (LDA) | ABSA via LLM |
|--|--|--|
| 출력 단위 | 문서 1개 → 토픽 1개 | 문장 내 속성 다수 → 각각의 감성 |
| 정보 손실 | **51.2%** | 낮음 |
| 해석 | "이 리뷰는 배송 토픽" | "배송 긍정, 포장 부정" |

**제품 기획 시사점**: 이는 NetMiner의 알려진 **"감성 Lab vs ABSA 격차"**를 뒷받침하는 직접 근거다. 리뷰·서비스 평가 분석 수요가 있는 마케팅/관광 세그먼트에서 ABSA 부재는 실질적 진입 장벽이다. **단기 도입 후보 1순위.**

### 멀티모달 감성 융합 — 새로 부각된 구조적 격차

> 근거: 청크 3, 청크 6 (성장 클러스터)

**텍스트 + 이미지 + 음성 + 영상**을 융합한 감성 분석이 응용 분야의 성장 패턴으로 자리잡고 있다(~25편). 확인된 구성:
- mBERT / CNN-LSTM / SBERT 융합 (관광 도메인, 다국가 병렬 — 청크 6)
- YOLO + BERT 융합 (이미지+텍스트 — 청크 2)
- Whisper AI로 음성 전사 후 텍스트 감성 분석 (청크 5)

**NetMiner 관점**: ❌ 완전 미지원. NetMiner는 텍스트 전용이며, 이는 기능 하나의 부재가 아니라 **데이터 모달리티 차원의 구조적 한계**다. 단기 대응은 비현실적이며, "텍스트+네트워크 통합"이라는 기존 강점 축을 더 깊게 파는 것이 합리적 대응이다.
