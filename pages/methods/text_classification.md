# 텍스트 분류 (Text Classification)

문서·문장·단락 단위의 텍스트를 미리 정의된 범주로 자동 분류하는 방법론. 응용 분야 논문에서 약 76편(20%)에 핵심 방법론으로 사용되어 **3위**를 기록했다. 감성 분석이 "긍정/부정 극성"에 특화된 반면, 텍스트 분류는 주제·의도·유형 등 다양한 범주를 다루는 더 넓은 개념이다.

---

## 감성 분석과의 차이

| 구분 | 텍스트 분류 | 감성 분석 |
|------|------------|----------|
| 목적 | 범주 할당 (주제, 의도, 유형 등) | 감정·의견 극성 탐지 |
| 레이블 예시 | 스팸/정상, 가짜뉴스/사실, 정치적 입장 | 긍정/부정/중립, 분노/기쁨 |
| 대표 모델 | BERT, RoBERTa, DeBERTa | BERT-Sentiment, VADER, ABSA |

실제 논문에서는 두 방법을 파이프라인으로 결합하는 경우가 많다 (텍스트 분류 → 카테고리 내 감성 분석).

---

## 주요 방법론

### Transformer 기반 (주류)

| 모델 | 특징 | 주요 응용 분야 |
|------|------|---------------|
| **BERT / RoBERTa** | 양방향 사전훈련, 파인튜닝 | 뉴스 분류, 법률 문서, 허위정보 |
| **DeBERTa** | 분리된 어텐션, BERT 개선 | 벤치마크 성능 향상 |
| **DistilBERT** | 경량화, 추론 속도 우선 | 실시간 분류, 소규모 데이터 |
| **도메인 특화 BERT** | AraBERT, IndoBERT, KoBERT 등 | 비영어권 분류 |
| **GPT 제로샷 분류** | 레이블 없이 프롬프트로 분류 | 소규모·신규 범주 |

### 앙상블 / 하이브리드

| 방법 | 구성 | 특징 |
|------|------|------|
| **BERT + SVM** | BERT 임베딩 → SVM 분류 | 소규모 데이터 안정적 |
| **CNN + LSTM** | 지역 특징 + 순서 의존성 | 문장 수준 분류 |
| **TF-IDF + 앙상블 ML** | 특징 추출 → RF·XGBoost | 전통적 접근, 해석 용이 |

## 응용 분야 사용 패턴 (2026, 379편 기반)

| 응용 맥락 | 편수 | 대표 도구 |
|-----------|------|----------|
| **허위정보 / 가짜뉴스 탐지** | ~18 | BERT, RoBERTa, XGBoost |
| **법률 문서 분류** | ~12 | LegalBERT, DeBERTa |
| **정치 텍스트 자동 코딩** | ~10 | GPT 제로샷, BERT 파인튜닝 |
| **의료 임상 텍스트 분류** | ~10 | BioClinicalBERT |
| **독성 / 혐오 표현 탐지** | ~8 | HateBERT, 멀티레이블 분류 |
| **스팸 / 피싱 탐지** | ~6 | 앙상블 ML, CNN |
| **기타 (ESG, 교육, 관광 등)** | ~12 | 도메인별 다양 |

> 허위정보·정치텍스트 코딩에서 **GPT 제로샷 분류**가 파인튜닝 모델을 성능 면에서 따라잡거나 초과하는 논문이 다수 등장. LLM 기반 분류와 전통 파인튜닝 방식의 경계가 흐려지는 추세.

---

## 도전 과제

- **레이블 불균형**: 가짜뉴스·혐오 표현 데이터는 부정 클래스가 극소수 — 오버샘플링, 클래스 가중치 필요
- **도메인 이동(Domain Shift)**: 학습 도메인과 다른 텍스트에서 성능 급락 → 도메인 특화 사전훈련 필요
- **다국어 분류**: 언어별 토크나이저 차이, 저자원 언어 성능 저하
- **제로샷의 한계**: GPT 기반 분류는 비용·재현성 문제 — 벤치마크 비교 어려움

## NetMiner 지원 현황

⚠️ **부분 지원** — NetMiner는 텍스트 분류 기능 일부를 지원하지만 BERT·Transformer 기반 분류는 직접 실행 불가.

**워크플로우 접점**:
- 분류 결과(레이블)를 입력 데이터로 활용해 **네트워크 분석** 수행 가능
  - 예: 뉴스 기사를 외부 도구로 주제 분류 → 주제별 의미연결망 비교 분석
- NetMiner의 **텍스트 마이닝** 기능으로 키워드 기반 간단 분류 가능

**미지원 기능**: Transformer 파인튜닝, GPT API 연동, 도메인 특화 모델 배포
