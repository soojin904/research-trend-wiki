# 체계적 문헌 고찰 (Systematic Literature Review, SLR)

특정 주제의 기존 연구를 사전에 정의된 프로토콜로 체계적으로 수집·분석하는 연구 방법.

## 전통적 SLR의 한계와 데이터마이닝 결합
- 전통 SLR: 연구자가 수작업으로 읽고 분류 → 규모 한계, 주관성
- **데이터마이닝 기반 SLR**: 대규모 논문 자동 처리 → 객관적 트렌드 파악

### 결합 워크플로우
1. 논문 수집 (DB 검색)
2. 키워드 추출 + 전처리
3. [[semantic_network_analysis\|의미연결망]] 또는 [[keyword_network_analysis\|키워드 네트워크]] 분석
4. [[topic_modeling\|토픽모델링]] (LDA)
5. 시계열 트렌드 분석
6. 정성 해석 (연구자)
