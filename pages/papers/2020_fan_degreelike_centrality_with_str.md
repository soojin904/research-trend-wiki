# Degree-like centrality with structural zeroes or ones: When is a neighbor not a neighbor?
**제목(한글)**: 구조적 0 또는 1이 있는 차수 유사 중심성: 이웃이 이웃이 아닌 경우는?

**저자**: Min Fan; Zhulou Cao; Jieting Cheng; Fang Yang; Xingqin Qi
**출처**: Social Networks, Vol.63, pp.38–46
**발행일**: 2020-05-29
**DOI**: https://doi.org/10.1016/j.socnet.2020.05.002

## 한국어 요약

**연구질문**: 네트워크에서 구조적으로 연결이 불가능한 쌍(structural zeroes)이나 필수 연결 쌍(structural ones)이 존재할 때 차수 기반 중심성 측도를 어떻게 수정해야 하는가?

**방법론**:
- 구조적 0과 1을 고려한 차수 유사 중심성(degree-like centrality) 측도 개발
- 수학적 및 통계적 이론 분석
- 실제 네트워크 데이터 적용 검증

**주요 결과**:
- 구조적 제약이 있는 네트워크에서 기존 차수 중심성의 한계 지적
- 구조적 0/1을 반영한 수정 중심성 측도 제안
- 중심성 측도의 적용 범위 확장
