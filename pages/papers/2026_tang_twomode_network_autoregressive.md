# Two-mode network autoregressive model for network analysis with core nodes

**제목(한글)**: 핵심 노드를 포함한 네트워크 분석을 위한 이원 네트워크 자기회귀 모델

**저자**: Huiyun Tang; Moxuan Mi; Yingying Ma; Haisheng Yang; Feifei Wang
**출처**: Social Networks, Vol.86, pp.75–87
**발행일**: 2026-02-05
**DOI**: https://doi.org/10.1016/j.socnet.2026.01.004

## 한국어 요약

**연구질문**: 핵심 노드(core node)를 갖는 이원 네트워크(two-mode network) 구조를 자기회귀 모델로 어떻게 분석할 수 있는가?

**방법론**:
- 이원 네트워크(행위자-사건 또는 행위자-속성 네트워크)에 적합한 자기회귀 모델(STAR model 계열) 개발
- 핵심 노드의 구조적 역할을 명시적으로 모델에 반영
- 네트워크 다양성(variety)과 자기회귀 의존성을 결합한 추정 절차 제안

**주요 결과**:
- 이원 네트워크 내 핵심 노드가 전체 네트워크 동학에 비대칭적 영향을 미침을 이론적으로 확인
- 제안 모델이 기존 일원 네트워크 자기회귀 모델 대비 이원 구조 포착에 우수
- 금융·사회 네트워크 등 핵심-주변부 구조를 가진 실증 자료에 적용 가능
