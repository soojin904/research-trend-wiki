# Reprint of: Network Canvas: Key decisions in the design of an interviewer-assisted network data collection software suite
**제목(한글)**: 재수록: 네트워크 캔버스 — 인터뷰 보조 네트워크 데이터 수집 소프트웨어 설계의 핵심 결정 사항

**저자**: Michelle Birkett; Joshua Melville; Patrick Janulis; Gregory Phillips; Noshir Contractor; Bernie Hogan

**발행일**: 2022-01-31
**DOI**: https://doi.org/10.1016/j.socnet.2022.01.006

## 한국어 요약

**연구질문**: 인터뷰 보조 방식의 네트워크 데이터 수집 소프트웨어인 Network Canvas를 설계할 때 어떤 핵심 결정 사항들이 있었으며, 사용성과 워크플로우에 어떻게 영향을 미쳤는가?

**방법론**:
- Network Canvas 소프트웨어 스위트(suite) 설계 과정 기술
- 사용성(usability) 및 워크플로우 설계 원칙 적용
- 인터뷰 보조 방식과 자기 보고 방식의 데이터 수집 비교

**주요 결과**:
- 인터뷰 보조 방식에 최적화된 Network Canvas 설계 원칙 도출 (재수록)
- 사용성 및 데이터 수집 효율성 향상을 위한 핵심 결정 사항 정리
- 연구자와 응답자 모두의 사용 경험을 고려한 설계 방법론 제시
