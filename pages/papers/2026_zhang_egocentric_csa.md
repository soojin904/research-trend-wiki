# The influence of social network on consumers' negative reactions toward corporate social advocacy

**연구질문**: 개인의 에고중심 네트워크 특성이 CSA(기업 사회적 옹호) 반응(부정적 구전·불매)에 어떤 영향을 미치는가?

**데이터**: 온라인 에고중심 네트워크 설문 — 참여자 178명, 알터 604명

## 방법론

| 단계 | 내용 |
|------|------|
| 설계 | 에고중심 네트워크 조사 (egocentric network survey) |
| 변수 | 네트워크 규모, 밀도, 태도 동질성(homophily), 응집도(cohesion) |
| 감정 | 분노(anger)·경멸(contempt)의 매개 효과 분석 |
| 결과 변수 | 부정적 구전(NWOM), 불매운동(boycott) 의도 |

## 주요 결과

- NWOM·불매 의도는 네트워크 규모·밀도보다 **알터의 태도**에 의해 결정됨
- 분노·경멸이 네트워크 특성 → 행동 의도 경로를 유의미하게 매개
- 응집도는 동조(conformity)를 증폭하지만, 궁극적 동기는 **공유된 의미와 정서적 공명**
