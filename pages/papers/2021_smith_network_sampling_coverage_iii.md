# Network sampling coverage III: Imputation of missing network data under different network and missing data conditions
**제목(한글)**: 네트워크 표본 커버리지 III: 다양한 네트워크 및 결측 조건에서의 네트워크 결측 데이터 대체

**저자**: Jeffrey A. Smith; Jonathan H. Morgan; James Moody
**출처**: Social Networks, Vol.68, pp.148–178
**발행일**: 2021-06-18
**DOI**: https://doi.org/10.1016/j.socnet.2021.05.002

## 한국어 요약

**연구질문**: 다양한 네트워크 구조 및 결측 데이터 조건에서 네트워크 결측 데이터를 대체(imputation)하는 방법들의 성능은 어떻게 차이나는가?

**방법론**:
- 다양한 네트워크 및 결측 데이터 조건에서 결측값 대체 방법 비교 분석
- 머신러닝(machine learning) 및 데이터 마이닝(data mining) 기반 대체 기법 적용
- 시뮬레이션을 통한 대체 방법의 정확도 평가

**주요 결과**:
- 결측 메커니즘과 네트워크 구조에 따라 적합한 대체 방법이 상이함
- 인공지능(AI) 기반 방법이 전통적 방법 대비 일부 조건에서 우수한 성능 발휘
- 네트워크 연구에서 결측 데이터 처리 방식이 분석 결과에 큰 영향을 미침
