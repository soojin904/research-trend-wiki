# Predicting network members from partial contact records on social media: A machine learning approach

**제목(한글)**: 소셜 미디어 부분 접촉 기록으로 네트워크 구성원 예측: 머신러닝 접근

**저자**: Shu-mei Lai; Tso-Jung Yen; Ming-Yi Chang; Yang-chih Fu; Wei‐Chung Liu
**출처**: Social Networks, Vol.80, pp.10–24
**발행일**: 2024-08-14
**DOI**: https://doi.org/10.1016/j.socnet.2024.08.004

## 한국어 요약

**연구질문**: 소셜 미디어의 부분적 접촉 기록만으로 개인 사회 네트워크의 구성원을 머신러닝을 활용해 예측할 수 있는가?

**방법론**:
- 소셜 미디어 플랫폼의 부분 접촉 기록 데이터 활용
- 머신러닝(machine learning) 기반 네트워크 구성원 예측 모델 개발
- 인공지능 및 데이터 과학 기법 적용

**주요 결과**:
- 부분적 접촉 기록에서 네트워크 구성원 예측이 가능함을 시연
- 소셜 미디어 기반 간접 네트워크 측정의 실용적 가능성 제시
- 개인 정보 접근이 제한된 상황에서의 네트워크 연구 방법론 기여
