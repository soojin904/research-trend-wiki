# A statistical model for the analysis of mobility tables as weighted networks with an application to faculty hiring networks
**제목(한글)**: 가중 네트워크로서의 이동 테이블 분석을 위한 통계 모델: 교수 채용 네트워크 적용 사례

**저자**: Per Block; Christoph Stadtfeld; Garry Robins
**출처**: Social Networks, Vol.68, pp.264–278
**발행일**: 2021-08-25
**DOI**: https://doi.org/10.1016/j.socnet.2021.08.003

## 한국어 요약

**연구질문**: 이동 테이블(mobility table)을 가중 네트워크(weighted network)로 모델링하고 통계적으로 분석하는 방법은 무엇이며, 교수 채용 네트워크에 어떻게 적용할 수 있는가?

**방법론**:
- 지수 랜덤 그래프 모델(ERGM, Exponential Random Graph Model)을 가중 네트워크로 확장
- 이동 테이블을 방향성 가중 네트워크로 변환하여 분석
- 교수 채용 네트워크 데이터에 모델 적용

**주요 결과**:
- 이동 테이블의 구조적 패턴(위계, 이웃성 등)을 네트워크 효과로 통계 검정 가능
- 교수 채용 네트워크에서 기관 간 지위 서열 및 상호성 효과 확인
- 소셜 네트워크 분석(SNA) 툴박스를 이동성 연구에 적용하는 새로운 프레임워크 제시
