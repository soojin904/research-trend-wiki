# Measuring centrality in film narratives using dynamic character interaction networks
**제목(한글)**: 동적 캐릭터 상호작용 네트워크를 활용한 영화 서사의 중심성 측정

**저자**: Pete Jones; Eithne Quinn; Johan Koskinen
**출처**: Social Networks, Vol.63, pp.21–37
**발행일**: 2020-04-29
**DOI**: https://doi.org/10.1016/j.socnet.2020.03.003

## 한국어 요약

**연구질문**: 동적 캐릭터 상호작용 네트워크를 통해 영화 서사에서 중심적 인물을 어떻게 측정할 수 있는가?

**방법론**:
- 동적 네트워크 분석 (Dynamic Network Analysis)
- 영화 내 캐릭터 상호작용을 시간에 따라 추적하는 내러티브 네트워크 구성
- 다양한 중심성(centrality) 측도 적용

**주요 결과**:
- 동적 캐릭터 네트워크가 영화 서사에서 중심적 인물을 효과적으로 식별
- 시간에 따른 중심성 변화로 서사 구조 분석 가능
