# Closeness centrality via the Condorcet principle
**제목(한글)**: 콩도르세 원리를 통한 근접 중심성

**저자**: Oskar Skibski
**출처**: Social Networks, Vol.74, pp.13–18
**발행일**: 2023-02-14
**DOI**: https://doi.org/10.1016/j.socnet.2023.01.005


## 한국어 요약

**연구질문**: 근접 중심성(closeness centrality)을 콩도르세 원리(Condorcet principle)에 기반하여 공리적으로 특성화할 수 있는가?

**방법론**:
- 공리적 접근(axiomatic approach)을 통한 중심성 척도 특성화
- 콩도르세 원리를 네트워크 노드 순위 결정에 적용
- 수학적 증명을 통한 근접 중심성의 유일성 논증

**주요 결과**:
- 근접 중심성이 콩도르세 원리를 만족하는 유일한 중심성 척도임을 증명
- 중심성 측정의 이론적 근거를 공리적으로 정립
- 순위(ranking) 기반 네트워크 분석에 새로운 이론적 기반 제공
