# Effects of smartphone use and recall aids on network name generator questions
**제목(한글)**: 스마트폰 사용과 기억 보조 도구가 네트워크 이름 생성 질문에 미치는 영향

**저자**: Christoph Beuthner; Henning Silber; Tobias Stark
**출처**: Social Networks, Vol.69, pp.45–54
**발행일**: 2020-07-21
**DOI**: https://doi.org/10.1016/j.socnet.2020.06.006

## 한국어 요약

**연구질문**: 설문 응답 시 스마트폰 사용과 기억 보조 도구(연락처 목록 등)의 활용이 네트워크 이름 생성 질문의 응답에 어떤 영향을 미치는가?

**방법론**:
- 실험적 설문 설계 (스마트폰 사용 여부, 기억 보조 도구 제공 여부 조건 비교)
- 독일 응답자 대상 설문 조사
- 이름 생성 질문 응답 품질 및 네트워크 특성 비교 분석

**주요 결과**:
- 스마트폰 사용 및 기억 보조 도구가 이름 생성 결과에 유의한 영향
- 도구 활용이 응답자 기억 편향(recall bias)을 줄이는 효과 제시
- 네트워크 데이터 수집의 방법론적 개선 방향 제안
