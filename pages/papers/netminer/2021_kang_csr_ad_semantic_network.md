# 광고홍보학 CSR 연구동향: 의미연결망 + 토픽모델링 (2003~2020)

## 연구 질문
광고홍보학 분야의 CSR 연구는 어떻게 발전해왔으며, 어떤 토픽이 주를 이루는가?

## 데이터
- 대상 학술지 5개: 광고학연구, 홍보학연구, 광고연구, 한국광고홍보학보, 광고홍보실학연구
- 기간: 2003~2020년 게재 논문 124편
- 분석 대상: 제목, 초록, 주제어

## 방법론
| 분석 | 내용 |
|------|------|
| [[semantic_network_analysis\|의미연결망 분석]] | 키워드 간 공출현 네트워크 구성 |
| [[topic_modeling\|토픽모델링]] (LDA) | 주요 연구 토픽 도출 |
| 도구 | [[netminer\|NetMiner 4]] |

## 주요 결과
**핵심 키워드**: 소비자, 전략, 태도, 인식, 커뮤니케이션 (허브 역할)

**7개 연구 토픽 (세부 내용 별도 분석 필요)**:
- CSR 적합성, CSR 동기 → 소비자 인식·태도에 미치는 영향이 주류
- 기업 위기 상황에서의 CSR 효과 검증 트렌드

**추세**:
- 2010년 이후 CSR 연구 급증
- 광고학연구가 주도적 위치

## NetMiner 연관성
- NetMiner 4 단일 도구로 의미연결망 + 토픽모델링 통합 수행
- 국내 학술 연구동향 분석에 NetMiner 활용 사례 → 학술 마케팅 자료로 활용 가능

## 메모
- [[semantic_network_analysis\|의미연결망]]이 [[keyword_network_analysis\|키워드 네트워크]]와 같은 의미로 사용됨
- ESG 이슈와 연결 → 향후 연구 확장 가능성 (ESG + 광고홍보학)
- 연구동향 분석 자체가 NetMiner 활용 사례 → 학술 커뮤니티 대상 세미나 사례로 활용 가능
