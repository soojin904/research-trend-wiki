# 초등학교 식물의 뿌리, 줄기, 잎에서 교사의 지도 개념과 학생의 획득 개념 네트워크

## 연구 질문
초등 과학 '식물의 구조와 기능' 단원에서 교사의 지도 개념과 학생의 획득 개념(직후/4주 후)은 네트워크 구조상 어떻게 다른가?

## 방법론
- 데이터: 대구 소재 초등학교 6학년 학생 57명, 교사 3명. 교사 개념은 수업 녹음·전사, 학생 개념은 수업 직후 및 4주 후 학습 기억 검사(즉시/장기 기억)로 수집
- 분석 기법: 언어 네트워크 분석, NetMiner 4.0을 활용한 개념 네트워크·주요 개념 네트워크·교사-학생 연결 개념 네트워크 분석, 아이겐벡터 중심성 분석

## 주요 결과
- 교사·학생 모두 뿌리·줄기·잎·물·양분 등 핵심 개념을 공통적으로 사용하나 네트워크 구조와 연결 양상은 상이
- 교사는 기능적으로 관련된 개념 중심의 명확한 구조, 학생은 기능적 관련성이 낮아도 다양한 개념을 연결하는 경향
- 수업 직후 학생 네트워크는 개념 나열적 특성이 강했으나 4주 후에는 후속 학습 영향으로 연결이 확장·재구성됨
- 아이겐벡터 중심성 분석 결과 4주 후 학생 네트워크에서 교사·직후 학생과 다른 개념이 부상, 인지 구조의 역동적 변화 확인

## NetMiner 연관성
교사·학생의 개념 텍스트를 NetMiner 4.0으로 언어 네트워크 분석하여 개념 네트워크를 구축하고, 아이겐벡터 중심성으로 시간에 따른 인지 구조 변화를 추적했다.
