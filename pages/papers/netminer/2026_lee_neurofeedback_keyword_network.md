# 키워드 네트워크를 활용한 뉴로피드백 연구 동향

## 연구 질문
2005~2024년 국내 뉴로피드백 연구는 시기별로 어떤 핵심 키워드와 구조적 공백(structural hole)을 보이며 변화해왔는가?

## 방법론
- 데이터: KCI 등재 학술지 117편에서 추출한 키워드 356개
- 도구: Excel, NetMiner 4x64
- 분석: 중심성 분석, 구조적 공백(structural hole) 분석, 4개 시기 구분 분석

## 주요 결과
- 전체 시기 핵심 키워드(높은 중심성): 뇌파, 주의집중력, 뇌기능
- 구조적 공백 분석 상위: 주의집중력, 뇌파, 주의력결핍과잉행동장애 — 서로 다른 연구영역을 잇는 매개자 역할
- 1기(심리·생리적 자기조절: 정서, 명상 등) → 2기(기술적 연구: 윈도우크기, 뇌-컴퓨터 인터페이스) → 3기(임상·교육 융합: ADHD, 불면증) → 4기(융합기술: 치매, 틱, 디지털콘텐츠)로 주제 확장

## NetMiner 연관성
NetMiner 4x64로 키워드 네트워크의 중심성 및 구조적 공백 분석을 수행해 뉴로피드백 연구의 핵심축과 매개 키워드를 도출했다.
