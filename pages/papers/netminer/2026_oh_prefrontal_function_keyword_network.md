# 임상 중심 전전두엽 기능 평가 및 중재 연구의 주제 구조: 키워드 네트워크 분석

## 연구 질문
임상적으로 초점화된 전전두엽(PFC) 기능 평가 및 중재 연구 문헌의 주제 조직과 구조적 연결 관계는 어떠한가?

## 방법론
- 데이터: 2014년 1월~2024년 12월 Web of Science, PubMed, Embase에서 수집한 동료심사 논문 1,301편
- 분석 기법: 키워드 추출·표준화 후 상위 52개 고빈도 용어를 NetMiner 4.0으로 분석. 밀도·포괄성·평균경로거리 등 네트워크 지수 산출, 연결·매개 중심성 분석, 응집 하위집단(cohesive subgroup) 분석

## 주요 결과
- 키워드 네트워크는 밀도 0.408, 포괄성 1.0, 평균거리 1.621로 고립 노드 없는 높은 연결 구조
- 중심 허브: Cognition, Depressive disorders, Randomized controlled trial, Cognitive behavioural therapy, Psychotherapy
- Mobile health, E-health intervention, Chronic illness group도 상당한 구조적 영향력 보유
- 응집 하위집단 분석으로 인지재활, 정서조절, 심리치료, 디지털 자기관리, 마음챙김 기반 실행기능 지원, 스트레스 회복력, 신경인지 동기 등 7개 주제 클러스터 도출

## NetMiner 연관성
1,301편 논문에서 추출한 고빈도 키워드 52개를 NetMiner 4.0으로 네트워크 지수·중심성·응집 하위집단 분석하여 전전두엽 기능 연구의 주제 구조를 매핑했다.
