# 코비6 농구화의 소비자 인식 구조 분석: 텍스트마이닝 기반 의미연결망 및 CONCOR 분석

## 연구 질문
온라인 텍스트 데이터를 통해 코비6 농구화에 대한 소비자 인식 구조(주요 키워드, 의미 관계, 인식 군집)는 어떻게 나타나는가?

## 방법론
- 데이터: 2020.1.26~2025.12.31 네이버 블로그·카페, 온라인 커뮤니티, 뉴스 기사에서 수집한 '코비6', 'Kobe basketball shoes' 등 검색어 기반 텍스트
- 분석 기법: Textom(수집·전처리·빈도·N-gram 분석), NetMiner(의미연결망 분석, 연결중심성 분석, CONCOR 분석)

## 주요 결과
- '코비', '코비6', '농구화'가 전체 네트워크의 중심 키워드
- '착화감', '쿠셔닝', '접지력', '디자인'은 제품 성능 인식, '리셀', '가격', '구매', '출시'는 소비·시장 인식과 관련
- CONCOR 분석 결과 '제품 및 소비 관련 인식' 군집과 '제품 특성 및 성능 인식' 군집으로 구분
- 코비6는 기능적 성능·브랜드 상징성·선수 이미지·희소성·리셀 시장 가치가 결합된 상징적 스포츠 제품으로 인식됨

## NetMiner 연관성
Textom으로 수집·전처리한 텍스트를 NetMiner로 의미연결망 분석, 연결중심성 분석, CONCOR 군집 분석하여 소비자 인식 구조를 규명했다.
