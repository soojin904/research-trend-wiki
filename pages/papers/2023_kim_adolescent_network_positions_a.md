# Adolescent network positions and memory performance in adulthood: Evidence from sibling fixed effects models with sociometric network data
**제목(한글)**: 청소년기 네트워크 위치와 성인기 기억 수행 능력: 형제 고정 효과 모형 연구

**저자**: Jinho Kim; Taehoon Kim
**출처**: Social Networks, Vol.76, pp.112–119
**발행일**: 2023-08-28
**DOI**: https://doi.org/10.1016/j.socnet.2023.08.002


## 한국어 요약

**연구질문**: 청소년기 네트워크 위치(중심성, 인기도 등)가 성인기 기억 능력에 장기적으로 영향을 미치는가?

**방법론**:
- 사회계측법(sociometric) 네트워크 데이터를 활용한 종단 분석
- 형제 고정 효과 모형(sibling fixed effects model)으로 가족 수준 교란 변수 통제
- 중심성(centrality)·인기도(popularity) 등 네트워크 위치 지표 사용

**주요 결과**:
- 청소년기 네트워크 중심적 위치가 성인기 기억 수행과 연관
- 형제 고정 효과 통제 후에도 네트워크 위치의 장기 효과 유지
- 사회적 네트워크 위치가 인지 발달에 미치는 인과적 영향 시사
