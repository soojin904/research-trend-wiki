# Estimating peer influence in multilayer networks

**연구질문**: 다층 네트워크 환경에서 동료 영향(peer influence)을 어떻게 일관되게 추정할 수 있는가?

**데이터**: 실증 연구 (초록 비공개)

## 키워드
동료 효과(peer effects), 내생성(endogeneity), 관찰 연구, 경험적 연구, SNA

## 핵심 관심사

| 이슈 | 내용 |
|------|------|
| 내생성 문제 | 동료 영향 추정 시 역인과·선택 편향 처리 |
| 다층 네트워크 | 복수의 관계 레이어를 통한 영향 경로 분리 |
| 추정 방법 | 다층 구조를 고려한 계량 추정 전략 |

## NetMiner 연관성

- 다층 네트워크 분석 기능 연구 방향 참고
- 동료 영향 모델링 → 확산(diffusion) 분석 관련
