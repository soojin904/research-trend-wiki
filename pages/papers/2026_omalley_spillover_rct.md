# Causal inference for intervention spillover in a stepped wedge cluster-randomized trial

**연구질문**: 의사 네트워크를 통한 스필오버가 stepped-wedge RCT의 인과 추론에 어떤 영향을 미치는가?

**데이터**: 전국 의료기관 의사 네트워크 + 종단 RCT 데이터 (advance care planning 개입)

## 방법론

| 단계 | 내용 |
|------|------|
| 설계 | Stepped-wedge cluster-randomized trial |
| 네트워크 | 의사 간 전문가 네트워크 (클러스터 간 연결) |
| 효과 분해 | 직접 효과 / 간접 효과(spillover) / 직접-간접 교호작용 |
| 추정 | 반사실적(counterfactual) 프레임워크 |

## 주요 결과

- 스필오버·오염(contamination)을 보정하면 직접 효과 추정치가 크게 달라짐
- 의사 스필오버 효과가 개입의 지속성을 강화(reinforce)함
- 네트워크 확산이 주로 대규모 physician spillover effect에 의해 구동됨

## NetMiner 연관성

- 직접 활용 사례는 없으나, **네트워크 기반 인과 추론** 연구 방법론 참고 가능
- 의사 공동 네트워크 구성 + 확산 분석 파이프라인
