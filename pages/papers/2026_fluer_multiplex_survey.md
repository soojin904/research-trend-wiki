# From survey data to social multiplex models: Incorporating interlayer correlation from multiple data sources

**연구질문**: 복수의 설문 데이터를 결합해 레이어 간 상관성을 포함한 소셜 멀티플렉스 모델을 어떻게 구성하는가?

**데이터**: 복수 데이터 소스 결합 (초록 비공개)

## 키워드
동질성(homophily), 멀티플렉스(multiplex), 상관(correlation), 대인 관계, 표집

## 핵심 관심사

| 이슈 | 내용 |
|------|------|
| 멀티플렉스 네트워크 | 동일 행위자 집합에 복수의 관계 유형(레이어) 존재 |
| 레이어 간 상관 | 한 레이어의 연결이 다른 레이어 연결에 미치는 영향 |
| 데이터 통합 | 서로 다른 설문 소스를 일관된 멀티플렉스 모델로 통합 |
