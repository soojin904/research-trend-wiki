# Understanding the personal networks of people experiencing homelessness in King County, WA

**연구질문**: 노숙 경험자의 퍼스널 네트워크는 어떤 구조를 가지며, 시간에 따라 어떻게 변화하는가?

**데이터**: 킹 카운티(워싱턴주) 노숙 경험자 3,000명 이상, 3년간(2022–2024) 종단 데이터 (미국 최대 규모)

## 방법론

| 단계 | 내용 |
|------|------|
| 표집 | Respondent-Driven Sampling (RDS) |
| 네트워크 유형 | 지인망, 친밀 우정망, 친족(동거)망, 동료 추천망 4종 |
| 데이터 | Aggregate Relational Data (ARD) 활용 |

## 주요 결과

- 지인망 평균 규모: 22–27명; 친밀 우정 평균: 4.9 → 4.19 (감소)
- 친족(동거) 네트워크는 소폭 증가 → 가족 공동 노숙 증가 시사
- 친밀 우정 감소 → 네트워크 밀도 저하, 사회적 고립 증가 가능성

## NetMiner 연관성

- 퍼스널 네트워크 분석 기능 적용 가능
- 종단 네트워크 변화 추적 → NetMiner 연구 사례로 활용 가능
