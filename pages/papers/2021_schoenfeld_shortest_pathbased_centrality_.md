# Shortest path-based centrality metrics in attributed graphs with node-individual context constraints
**제목(한글)**: 노드 개별 맥락 제약이 있는 속성 그래프에서의 최단 경로 기반 중심성 지표

**저자**: Mirco Schoenfeld; Jürgen Pfeffer
**출처**: Social Networks, Vol.77, pp.93–103
**발행일**: 2021-11-02
**DOI**: https://doi.org/10.1016/j.socnet.2021.10.004

## 한국어 요약

**연구질문**: 노드별 맥락 제약(context constraint)이 있는 속성 그래프(attributed graph)에서 최단 경로 기반 중심성(centrality) 지표를 어떻게 정의하고 계산할 수 있는가?

**방법론**:
- 속성 그래프에서 노드 개별 제약을 반영한 최단 경로(shortest path) 계산 방법론 제안
- 매개 중심성(betweenness centrality) 등 기존 지표를 맥락 제약 환경에서 재정의
- 해석 가능성(interpretability) 관점에서 지표 평가

**주요 결과**:
- 노드 맥락 제약을 반영하면 기존 중심성 지표보다 현실적인 정보 흐름 모델링 가능
- 네트워크 과학(network science) 분야에서 맥락 인식 중심성 지표의 유용성 입증
- 복잡 네트워크 분석에서 노드 이질성을 반영한 새로운 분석 프레임워크 제공
