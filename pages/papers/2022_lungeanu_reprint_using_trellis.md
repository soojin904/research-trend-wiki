# Reprint of: Using Trellis software to enhance high-quality large-scale network data collection in the field
**제목(한글)**: 재수록: Trellis 소프트웨어를 활용한 현장 대규모 고품질 네트워크 데이터 수집 향상

**저자**: Alina Lungeanu; Mark McKnight; Rennie Negron; Wolfgang Munar; Nicholas A. Christakis; Noshir Contractor
**출처**: Social Networks, Vol.69, pp.293–306
**발행일**: 2022-01-31
**DOI**: https://doi.org/10.1016/j.socnet.2022.01.004

## 한국어 요약

**연구질문**: Trellis 소프트웨어가 현장에서 대규모 네트워크 데이터 수집의 품질과 효율성을 어떻게 향상시키는가?

**방법론**:
- Trellis 소프트웨어 활용 현장 네트워크 데이터 수집 과정 기술
- 메타데이터 관리 및 데이터 리터러시 향상 방법 적용
- 현장(field) 적용 사례를 통한 소프트웨어 유효성 검증

**주요 결과**:
- Trellis가 대규모 현장 네트워크 데이터 수집의 품질 향상에 기여 (재수록)
- 현장 데이터 수집에서의 메타데이터 관리 문제 해결 방안 제시
- 사회 네트워크 현장 연구를 위한 디지털 도구의 실용적 지침 제공
