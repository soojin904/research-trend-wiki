## 초록 (원문)

This chapter introduces machine learning as a new methodological tool in the social sciences. It explains how supervised machine learning enhances prediction through labeled data and how unsupervised machine learning identifies hidden structures in unstructured materials such as texts and images. Together, these approaches expand the analytical capacity of social research, integrating interpretation, explanation, and prediction within an evolving scientific paradigm.
