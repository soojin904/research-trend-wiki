# Web crawling and RSS as media monitoring tools: experience in development and application

**저자**: S. V. Oleinikov; I. I. Golovachuk
**출처**: Communicology, Vol.14, pp.50-64
**발행일**: 2026-10-01
**DOI**: https://doi.org/10.21453/2311-3065-2026-14-3-50-64

## 초록 (원문)

This article explores web crawling and RSS as essential tools for automating media monitoring amid increasing information flows. The study aims to develop and test an adaptive automated media data collection system based on web crawling and RSS technologies to optimize media monitoring processes. It describes the methodology for developing crawlers using Python and specialized libraries (BeautifulSoup, newspaper3k, feedparser, Selenium), as well as the modular architecture of the system and the principles of «polite crawling». Special attention is given to system adaptability for different types of web resources, integration with the humanities context, and the use of artificial intelligence for text analysis and annotation. The article presents practical testing on news resources from Transnistria, including a comparison between HTML page parsing and RSS feeds. The study demonstrates that a combined approach ensures efficient data collection, reduces editorial labor, and enhances media analysis quality.
