# Mapping the relational ecology of multi-organizational coalitions and collaboratives

**연구질문**: 다중 조직 연합(coalition)의 네트워크 연구에서 간과되는 복잡성(다층 구조, 외부 임베딩)은 무엇이며, 어떤 설계로 대응할 수 있는가?

**데이터**: 미국 테네시 주 48개 지역 약물남용 예방 연합(SMPC) 경험 기반

## 방법론

| 관점 | 내용 |
|------|------|
| 설계 논의 | 연구 경계 설정 문제, 내부 vs. 외부 네트워크 |
| 다층 구조 | 개인 간 ties + 조직 간 ties 동시 고려 필요 |
| 임베딩 | 연합 외부 행위자·조직과의 영향력 있는 관계 포함 필요 |

## 주요 결과 (논증)

- 기존 SNA 연구의 두 가지 맹점: **다층성 무시**, **외부 관계 무시**
- 연합 내부 조직간 네트워크 연구 → 개인 간 차원 누락
- 연합 경계 내 네트워크 → 가장 영향력 있는 외부 연결 누락
- 다층·외부 포함 설계가 연합 복잡성 이해를 강화함

## NetMiner 연관성

- **다층 네트워크(multilevel/multiplex)** 분석 기능 개발 방향 참고
- 조직 네트워크 분석 사례 연구로 활용 가능
