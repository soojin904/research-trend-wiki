# Bipartite exponential random graph models with nodal random effects
**제목(한글)**: 노드 무작위 효과를 포함한 이분 지수 랜덤 그래프 모델

**저자**: Sevag Kevork; Göran Kauermann
**출처**: Social Networks, Vol.70, pp.90–99
**발행일**: 2021-11-29
**DOI**: https://doi.org/10.1016/j.socnet.2021.11.002

## 한국어 요약

**연구질문**: 이분 그래프(bipartite graph)에 노드 수준의 무작위 효과(nodal random effects)를 포함한 지수 랜덤 그래프 모델(ERGM)을 어떻게 설계하고 추정할 수 있는가?

**방법론**:
- 이분 지수 랜덤 그래프 모델(bipartite ERGM)에 노드별 무작위 효과 도입
- 혼합 모델(mixed model) 프레임워크에서 추정 알고리즘 개발
- 지수 함수 기반 확률 모델로 네트워크 구조의 이질성 반영

**주요 결과**:
- 노드 수준의 관측되지 않은 이질성(unobserved heterogeneity)을 무작위 효과로 통제 가능
- 이분 네트워크에서 추정 안정성 향상
- 대규모 이분 네트워크 분석에 적용 가능한 효율적 추정 절차 제공
