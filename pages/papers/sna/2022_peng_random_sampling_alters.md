# Random sampling of alters from networks: A promising direction in egocentric network research
**제목(한글)**: 네트워크에서 알터의 무작위 표집: 자아중심 네트워크 연구의 유망한 방향

**저자**: Siyun Peng; Adam R. Roth; Brea L. Perry
**출처**: Social Networks, Vol.72, pp.52–58
**발행일**: 2022-09-13
**DOI**: https://doi.org/10.1016/j.socnet.2022.09.004

## 한국어 요약

**연구질문**: 자아중심 네트워크(egocentric network) 연구에서 전체 네트워크 대신 알터(alter)를 무작위 표집하는 방법은 연구 효율성과 데이터 품질에 어떤 이점을 제공하는가?

**방법론**:
- 표본 크기 결정(sample size determination) 및 신호 처리 표집(sampling) 이론 검토
- 퍼스널 네트워크 연구에서 알터 무작위 표집 방법 비교
- 응답자 부담 감소와 데이터 품질 간의 균형 분석

**주요 결과**:
- 알터 무작위 표집이 연구 실행 가능성과 데이터 품질을 동시에 향상 가능 (초록 비공개로 추정)
- 퍼스널 네트워크 연구에서의 방법론적 혁신 방향 제시
- 표본 크기와 편향 간의 트레이드오프 분석을 통한 실용적 지침 제공
