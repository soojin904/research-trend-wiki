# Parameter estimation procedures for exponential-family random graph models on count-valued networks: A comparative simulation study
**제목(한글)**: 계수형 네트워크에서 지수 계열 랜덤 그래프 모형의 모수 추정: 비교 시뮬레이션 연구

**저자**: Peng Huang; Carter T. Butts
**출처**: Social Networks, Vol.76, pp.51–67
**발행일**: 2023-07-28
**DOI**: https://doi.org/10.1016/j.socnet.2023.07.001


## 한국어 요약

**연구질문**: 계수형(count-valued) 네트워크에 적용되는 지수 계열 랜덤 그래프 모형(ERGM)의 다양한 모수 추정 방법들은 성능 면에서 어떻게 다른가?

**방법론**:
- 계수형 네트워크용 ERGM의 여러 추정 절차 비교
- 시뮬레이션 연구를 통한 추정 방법 성능 평가
- 편향, 분산, 계산 효율성 등 다양한 기준으로 방법론 비교

**주요 결과**:
- 계수형 네트워크에 대한 ERGM 추정 방법들의 성능 차이 규명
- 특정 조건에서 우수한 추정 방법 식별
- 연구자를 위한 추정 방법 선택 지침 제공
