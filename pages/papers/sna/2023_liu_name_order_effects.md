# Name order effects in measuring adolescent social networks using rosters
**제목(한글)**: 명단을 이용한 청소년 사회 네트워크 측정에서 이름 순서 효과

**저자**: Shuyin Liu; David A. Nolin; James A. Kitts
**출처**: Social Networks, Vol.76, pp.68–78
**발행일**: 2023-08-09
**DOI**: https://doi.org/10.1016/j.socnet.2023.07.002


## 한국어 요약

**연구질문**: 명단 기반 청소년 사회 네트워크 측정에서 이름의 순서가 네트워크 측정값에 영향을 미치는가?

**방법론**:
- 청소년 네트워크 측정 시 명단(roster) 방식 활용
- 이름 순서를 실험적으로 조작하여 측정 결과 비교
- 사회계측법(sociometry) 데이터 분석

**주요 결과**:
- 명단에서 이름 순서가 네트워크 지목(nomination) 결과에 영향
- 이름 순서 효과가 청소년 네트워크 측정의 방법론적 편향 유발
- 명단 설계 시 이름 순서를 고려한 측정 설계의 중요성 강조
