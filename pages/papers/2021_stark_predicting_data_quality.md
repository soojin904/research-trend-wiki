# Predicting data quality of proxy reports in egocentric network studies
**제목(한글)**: 자아 중심 네트워크 연구에서 대리 응답의 데이터 품질 예측

**저자**: Tobias Stark; Volker Stocké
**출처**: Social Networks, Vol.66, pp.38–49
**발행일**: 2021-02-11
**DOI**: https://doi.org/10.1016/j.socnet.2021.01.007

## 한국어 요약

**연구질문**: 자아 중심 네트워크(egocentric network) 연구에서 대리 응답자(proxy respondent)의 응답 품질을 어떤 요인들이 예측하는가?

**방법론**:
- 대리 응답 데이터와 실제 응답 데이터의 일치도 비교 분석
- 만족화(satisficing) 전략과 관련된 응답 패턴 분석
- 독일어권 데이터를 활용한 실증 연구

**주요 결과**:
- 대리 응답자의 특성(사회심리적 변수 등)이 데이터 품질에 영향을 미침
- 만족화 전략이 데이터 정확성을 저하시키는 주요 요인으로 확인
- 자아 중심 네트워크 연구 설계 시 대리 응답의 한계를 고려할 필요
