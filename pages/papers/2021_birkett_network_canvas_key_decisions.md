# Network Canvas: Key decisions in the design of an interviewer-assisted network data collection software suite
**제목(한글)**: Network Canvas: 면접관 보조 네트워크 데이터 수집 소프트웨어 설계의 주요 결정 사항

**저자**: Michelle Birkett; Joshua Melville; Patrick Janulis; Gregory Phillips; Noshir Contractor; Bernie Hogan
**출처**: Social Networks, Vol.66, pp.114–124
**발행일**: 2021-02-23
**DOI**: https://doi.org/10.1016/j.socnet.2021.02.003


## 한국어 요약

**연구질문**: 면접관 보조 방식의 네트워크 데이터 수집 소프트웨어를 설계할 때 어떤 핵심 결정 사항들을 고려해야 하는가?

**방법론**:
- 소프트웨어 설계 및 개발 과정에서의 설계 결정 사례 분석
- 사용성(usability) 및 워크플로우 관점에서의 평가

**주요 결과**:
- 네트워크 데이터 수집을 위한 전용 소프트웨어 스위트 개발 및 주요 설계 결정 사항 제시
- 데이터 수집의 효율성과 사용자 친화성을 높이는 인터페이스 설계 원칙 도출
- 현장 데이터 수집 환경에서의 소프트웨어 배포 및 운용 방안 논의
