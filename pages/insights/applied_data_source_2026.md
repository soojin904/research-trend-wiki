## 2. 소셜미디어 플랫폼 세부 분포

소셜미디어가 전체의 약 40%를 차지하며 단연 최다 활용 데이터 소스.

| 플랫폼 | 추정 편수 | 주요 연구 맥락 |
|--------|-----------|----------------|
| **Twitter / X** | ~135 | 정책 여론, 선거, 기후 담론, 정신건강, 허위정보 |
| **YouTube** | ~45 | 댓글 감성, 교육 콘텐츠 반응, 광고 효과 |
| **Facebook** | ~36 | 뉴스 페이지 댓글, 지역 커뮤니티, 정치 반응 |
| **Reddit** | ~22 | 커뮤니티 담론, 에코챔버, 건강 포럼 |
| **Instagram** | ~14 | 브랜드·마케팅, 이미지+텍스트 멀티모달 |
| **Weibo / WeChat** | ~13 | 중국어 텍스트 분석, 중국 여론 연구 |
| **VKontakte (VK)** | ~4 | 러시아어 텍스트, 동유럽 연구 |
| **TikTok / Douyin** | ~5 | 숏폼 콘텐츠 감성, 중국 국영미디어 분석 |

### Twitter/X 주도 이유

- **공개 API** 접근이 오랫동안 용이했음 (2023년 API 유료화 이후 감소 추세 시작)
- **정치·사회 이슈** 실시간 반응 데이터로 최적
- 140/280자 단문 → 감성 분석·토픽모델링에 적합한 규모

## 7. NetMiner 관점 시사점

### 7-1. 데이터 연동 기회

| 데이터 소스 | NetMiner 연동 현황 | 기회 |
|------------|-------------------|------|
| 트위터/X | ✅ Extension 있음 | 수집 → 의미연결망 워크플로우 케이스 스터디 |
| 뉴스 기사 | ✅ Extension 있음 | 담론 분석 파이프라인 강조 |
| 학술 데이터베이스 | ✅ Scopus/WoS 연동 | 서지계량 SLR 연구자 타깃 |
| Amazon/리뷰 | ❌ 직접 연동 없음 | 마케팅 분야 연구자에게 수동 수집 후 분석 가이드 |
| 의료 / 법률 | ❌ | 전문 도메인 — 진입 어려움 |

### 7-2. 고객 세그먼트별 주요 데이터 소스

| 고객 세그먼트 | 주로 쓰는 데이터 소스 | NetMiner 접점 |
|--------------|---------------------|---------------|
| 마케팅 연구자 | Amazon 리뷰, SNS 광고 반응 | 중간 (수동 수집 후 분석 가능) |
| 커뮤니케이션 연구자 | Twitter/X, 뉴스 기사 | 높음 (Extension 활용) |
| 보건 연구자 | Twitter 정신건강 데이터 | 중간 |
| 서지계량 / SLR 연구자 | Scopus, WoS, PubMed | 높음 (키워드 네트워크 분석) |
| 정치학 연구자 | 의회 발언록, 정당 SNS | 낮음 (정치 텍스트 분류 도구 없음) |
