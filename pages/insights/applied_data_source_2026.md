- **공개 API** 접근이 오랫동안 용이했음 (2023년 API 유료화 이후 감소 추세 시작)
- **정치·사회 이슈** 실시간 반응 데이터로 최적
- 140/280자 단문 → 감성 분석·토픽모델링에 적합한 규모

## 5. 언어 분포 — 저자원 언어 NLP는 지속 교차 클러스터 (789편 전수 확인)

**확정 발견**: 저자원 언어 NLP는 일시적 급증이 아니라 **789편의 약 15–20%를 차지하는 지속적 교차 클러스터**다. 7개 청크 **전부**에서 독립적으로 관찰되었다.

| 언어군 | 편수(추정) | 확인된 특화 모델 / 자원 | 관찰 청크 |
|--------|-----------|------------------------|----------|
| **아랍어** | ~40 | AraBERT, CAMeL, AfroXLMR(북아프리카) | 0, 1, 2 |
| **인도네시아어** | ~35 | IndoBERT, IndoBERTweet, InSet Lexicon | 0, 1, 2, 3 |
| **중국어** | ~25 | 중국어 BERT, Weibo 코퍼스 | 1, 3, 5, 6 |
| **아프리카 언어** (하우사·요루바·암하라 등) | ~20 | **AfroXLMR** | 2 |
| **방글라어 · 네팔어** | ~15 | 다국어 BERT 파인튜닝 | 0, 1 |
| **카자흐어 · 타직어** | ~10 | **TajikNLP** (신규 오픈소스 툴킷) | 0, 2 |
| **헝가리어 · 터키어 · 포르투갈어 · 러시아어** | ~20 | BERTimbau-LoRA, RuBioBERT | 0, 3, 4 |
| **스페인어** | ~18 | 다국어 감성 | 1, 4 |

### 전략적 의미

1. **비영어 시장은 "영어 도구의 번역"이 아니라 "언어 특화 모델"을 요구한다.** NetMiner의 텍스트 기능은 한국어·영어·중국어 3개 언어 지원 — 이 클러스터 전체가 사실상 접근 불가 영역이다.
2. 동시에 이 클러스터는 **개별 언어당 연구자 수가 적고 지역 저널 중심**이라 상업적 규모가 작다. 해외 확장 시 **언어 확대보다 한국어 강점 유지 + 영어권 도메인 세그먼트 공략**이 비용 대비 효과가 높다.
3. 다만 **BERT 기반 감성 분석 Lab 기능이 이미 7개 언어(영·독·네덜란드·프랑스·스페인·이탈리아·한국어)를 지원**한다는 점은 미활용 자산 — 유럽어권 소구 포인트로 활용 가능.

## 5-A. ⭐ "포스트-API 시대" 데이터 수집 위기 — 핵심 시장 신호

> 근거: `stracqualu` (청크 1). 플랫폼 API 제한으로 인한 소셜미디어 데이터 수집 위기를 명시적으로 다룬 논문.

### 무슨 일이 벌어지고 있나

- Twitter/X 학술 API 유료화(2023), Reddit API 과금, Meta CrowdTangle 종료 등으로 **연구자의 소셜미디어 원천 데이터 접근이 구조적으로 차단**되었다.
- 그 결과 789편에서 관찰되는 패턴:
  - **공개 벤치마크 데이터셋 재사용 증가** (SemEval, HuggingFace Datasets 등) — 새 현상을 못 다루고 기존 데이터를 재분석
  - **YouTube 댓글·뉴스 기사·리뷰 플랫폼으로 데이터 소스 이동** (여전히 접근 가능한 소스)
  - **의회·법원·SEC 등 기관 공개 문서로 회귀** — API가 필요 없는 대형 코퍼스

### NetMiner SNS Extension 포지셔닝에 주는 시사점

| 관찰 | 시사점 |
|------|--------|
| 연구자에게 **데이터 수집 자체가 병목**이 됨 | 분석 기능이 아니라 **"수집 가능한 데이터를 준다"**는 것이 구매 동기가 될 수 있다 |
| NetMiner SNS Data Collector는 **유튜브** 지원 | 트위터가 막힌 지금 **유튜브는 남아 있는 몇 안 되는 접근 가능 소스** — 우연히 유리한 위치 |
| News Data Collector(한국 뉴스), Biblio Collector(OpenAlex/KCI/Springer) | API 위기의 영향을 받지 않는 소스들 — **안정성이 강점** |

> **마케팅 메시지 후보**: "API가 막혀도 분석은 계속된다 — 수집부터 분석까지 한 도구에서."
> 단, SCHEMA 규칙 3 주의: 이 논리는 **SNS/News/Biblio Extension**에 한해 성립한다. 에고넷 설문·인터뷰 기반 수집 논문과는 연결하지 말 것(그쪽은 **Ego Network Extract** 기능 매칭).

## 6. 데이터 수집 방법

| 수집 방법 | 편수 | 특징 |
|-----------|------|------|

| **학술 데이터베이스** (Scopus API, PubMed E-utilities) | ~72 | 서지계량·SLR 연구 |

## 7. NetMiner 관점 시사점

### 7-1. 데이터 연동 기회

| 데이터 소스 | NetMiner 연동 현황 | 기회 |
|------------|-------------------|------|
| 유튜브 | ✅ SNS Data Collector | **포스트-API 시대의 실질적 강점** — 남아 있는 접근 가능 소스 |
| 트위터/X | ❌ 직접 수집 없음 (플랫폼 API 제한) | 업계 전체 공통 제약 — 차별점 아님 |
| 뉴스 기사 (한국) | ✅ News Data Collector | 담론 분석 파이프라인 강조 |
| 학술 데이터베이스 | ✅ Biblio Collector (OpenAlex, KCI, Springer) | 서지계량 SLR 연구자 타깃. **pyBiblioNet·VOSviewer와 직접 경쟁** |
| Amazon/리뷰 | ❌ 직접 연동 없음 | 마케팅 분야 연구자에게 수동 수집 후 분석 가이드 |
| 의료 / 법률 | ❌ | 전문 도메인 — 진입 어려움 |

> 주: 이전 버전은 "트위터/X ✅ Extension 있음, Scopus/WoS 연동"으로 기재했으나 [[pages/tools/netminer|NetMiner 기능 목록]] 확인 결과 SNS Collector는 **유튜브**, Biblio Collector는 **OpenAlex/KCI/Springer**다 — 수정함.

### 7-2. 고객 세그먼트별 주요 데이터 소스

| 고객 세그먼트 | 주로 쓰는 데이터 소스 | NetMiner 접점 |
|--------------|---------------------|---------------|
| 마케팅 연구자 | Amazon 리뷰, SNS 광고 반응 | 중간 (수동 수집 후 분석 가능) |
| 커뮤니케이션 연구자 | Twitter/X, 뉴스 기사 | 높음 (Extension 활용) |
| 보건 연구자 | Twitter 정신건강 데이터 | 중간 |
| 서지계량 / SLR 연구자 | Scopus, WoS, PubMed | 높음 (키워드 네트워크 분석) |
| 정치학 연구자 | 의회 발언록, 정당 SNS | 낮음 (정치 텍스트 분류 도구 없음) |
