## 1. 데이터 수집 방법 분포

SNA 학술지 논문은 응용 분야와 달리 **직접 수집(1차 데이터)** 비중이 압도적으로 높다.

| 수집 방법 | 편수(추정) | 비율 | 특징 |
|-----------|-----------|------|------|
| **설문 / 에고넷 인터뷰** | ~28 | ~56% | 이름 생성기, 시각적 도구, 사회계량 지명 |
| **종단 / 패널 데이터** | ~14 | ~28% | 2–4회 추적, 기존 패널 데이터 활용 포함 |
| **2차 / 행정 데이터** | ~12 | ~24% | 조직 기록, 공공 문서, 역사 아카이브 |
| **실험 (RCT 포함)** | ~6 | ~12% | 스텝-웨지 RCT, 실험실 실험 |
| **온라인 / 디지털** | ~10 | ~20% | 플랫폼 API, 이미지 딥러닝, 온라인 커뮤니티 |

> 1편이 복수 방법을 사용하는 경우 포함. 합산 > 50.

## 2. 네트워크 데이터 유형

| 유형 | 편수 | 설명 |
|------|------|------|
| **에고중심 / 퍼스널 네트워크** | ~18 | 이름 생성기 + 알터 관계 질문, 알터 수 4–45명 |
| **전체 네트워크 (소시오메트리)** | ~15 | 학급·조직 단위 전수 조사, 노드 20–2,884 |
| **다층 / 멀티플렉스** | ~9 | 친구·조언·협력 등 복수 관계 동시 수집 |
| **온라인 SNS** | ~8 | 플랫폼 상호작용 로그, 해시태그 네트워크 |
| **집계 관계 데이터 (ARD/NSUM)** | ~4 | 은닉 집단 규모 추정, 포지션 생성기 |
| **이미지 / 사진 기반** | ~2 | 사망자 사진 공동 등장, 딥러닝 추출 |

## 3. 연구 대상 집단

| 집단 | 편수 | 대표 연구 맥락 |
|------|------|----------------|
| **일반 성인** (대표 표본) | ~12 | 국가 단위 패널, 지역 사회 표본 |
| **학생** | ~11 | 대학 신입생, 중고등학생, 학급 네트워크 |
| **조직 구성원** | ~10 | R&D팀, 의사 집단, 외과 수술팀, 이사회 |
| **취약 계층** | ~8 | 노숙인, 노인, 치매 환자, 마약 사용자 |
| **온라인 커뮤니티** | ~5 | 게임 플랫폼, 해킹 포럼, 디자이너 커뮤니티 |
| **역사적 인물** | ~2 | 포르투갈 제국 관료, 교황 선거 추기경 |

## 4. 주요 공개·표준 데이터셋

SNA 학술지 논문에서 재사용되는 공개 데이터셋은 소수이지만 반복적으로 등장한다.

### 종단 패널 데이터

| 데이터셋 | 국가 | 특징 |
|---------|------|------|
| **Add Health** | 미국 | 청소년 종단 건강·네트워크 조사 (학계 표준) |
| **BHPS** (British Household Panel Study) | 영국 | 가구 패널, Block 2022 등 활용 |
| **SSND** (Survey of Social Networks of the Dutch) | 네덜란드 | 에고넷 종단, Völker 2020·2025 |
| **LISS Panel** | 네덜란드 | 온라인 패널, 에고넷 포함 (Stulp 2020) |
| **ELSOC** (Chilean Longitudinal Social Survey) | 칠레 | 종단 SNA (Plaza 2025) |
| **SGSS** (Spanish General Social Survey) | 스페인 | 포지션 생성기 (Luken 2022) |

### 온라인 플랫폼 데이터

| 데이터셋 | 특징 |
|---------|------|
| **Travian** (게임 플랫폼) | 900개 연합, 17,000+ 플레이어 전체 네트워크 (Ghawi & Pfeffer 2025) |
| **Hacked forum** | 사이버 범죄 커뮤니티 구조 분석 (Girard & Décary-Hêtu 2025) |

### 특수 데이터

| 데이터셋 | 특징 |
|---------|------|
| **PKK 사망자 사진** | 20,645장 딥러닝으로 공동 등장 관계 추출 (Ballinger 2023) |
| **NASA Apollo 13 교신 기록** | 임무 수행 중 의사소통 네트워크 (Kamalabad 2023) |
| **Baltimore STEW-MAP** | 도시 환경 관리 조직 네트워크 (Livas 2025) |

## 5. 에고넷 데이터 수집 도구

SNA 학술지에서 에고넷 데이터 수집 방법론 자체가 독립 연구 주제로 등장한다.

| 도구 | 특징 |
|------|------|
| **Network Canvas** | 면접관 지원 소프트웨어, 시각적 네트워크 수집 |
| **GENSI** | 인터랙티브 시각적 이름 생성기 |
| **EgoNet** | 에고넷 인터뷰 표준 소프트웨어 |
| **동심원 지도** (Concentric circles) | 친밀도 기반 시각적 배치 |
| **접촉 일기법** (Contact diary) | 일상적 접촉 기록 → 퍼스널 네트워크 추론 |

→ 관련 개념: [[pages/concepts/personal_network|퍼스널·에고중심 네트워크]]

## 6. 응용 분야 vs SNA 학술지 — 데이터 소스 비교

| 항목 | SNA 학술지 (유형 B) | 응용 분야 (유형 C) |
|------|--------------------|--------------------|
| **주 수집 방법** | 직접 설문·인터뷰 (~56%) | API·크롤링 (~40%) |
| **가장 많은 데이터 유형** | 에고넷 인터뷰 (~36%) | 소셜미디어 텍스트 (~40%) |
| **종단 데이터** | 흔함 (~28%) | 드묾 (단면 텍스트 중심) |
| **데이터 규모** | 소–중규모 (20–3,000 노드) | 대규모 (수만–수백만 텍스트) |
| **공개 데이터셋 재사용** | 소수 표준 데이터셋 반복 | SemEval·IMDb 등 NLP 벤치마크 |
| **언어** | 영어 중심, 다국가 설문 | 다국어 비중 높음 (15–20%) |
| **윤리·IRB** | 필수 (인간 대상 연구) | 공개 데이터 활용 多 |

## 7. NetMiner 관점 시사점

### 7-1. SNA 학술지 데이터 연동 기회

| 데이터 소스 | NetMiner 연관성 | 콘텐츠 기회 |
|------------|----------------|-------------|
| **에고넷 인터뷰 결과** (Network Canvas 등) | ✅ Ego Network Extract | "수집 도구 → NetMiner 분석" 파이프라인 케이스 스터디 |
| **소시오메트리 조사** (학급·조직) | ✅ 직접 분석 가능 | 조직 SNA 분석 튜토리얼 |
| **종단 네트워크 데이터** | ⚠️ 부분 | 시계열 네트워크 시각화 강화 필요 |
| **ARD / NSUM 데이터** | ❌ | 특수 통계 방법 — 연구자용 틈새 |
| **온라인 플랫폼 데이터** | ✅ Extension (Twitter·뉴스) | 플랫폼 수집→SNA 분석 워크플로우 |

### 7-2. 고객 세그먼트별 주요 데이터 유형

| 세그먼트 | 주로 쓰는 데이터 | NetMiner 접점 |
|---------|----------------|---------------|
| 보건·복지 연구자 | 에고넷 인터뷰, 종단 패널 | 높음 — Ego Network 기능 |
| 조직·경영 연구자 | 소시오메트리, 행정 기록 | 높음 — 전체 네트워크 분석 |
| 교육 연구자 | 학급 소시오메트리, 학생 패널 | 높음 — 소규모 네트워크 |
| 커뮤니케이션 연구자 | 온라인 플랫폼, 텍스트 | 중간 — Extension 활용 |
| 방법론 연구자 | 실험·RCT 데이터 | 낮음 — 고급 통계 필요 |
