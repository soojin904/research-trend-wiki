# 응용 분야 논문 분석 방법론 빈도 (2026, 789편 기준)

> **분석 기준**: **789편** (2026-09-22 기준, `pages/papers/applied/` 개별 페이지 **전수 판독**)
> **이전 분석 대체**: 2026-05-27 592편 / 커버리지 80% (청크 8–9 미완) 기반 집계를 본 문서가 완전히 대체한다. 기준 편수 1.33배 확대 + 전수 커버리지.
> **집계 방법**: 7개 청크(112/111/112/111/115/114/114편)로 나눠 개별 페이지 초록·방법 섹션을 직접 판독. OpenAlex 자동 태그는 집계에 사용하지 않음(SCHEMA 규칙 1). 논문당 핵심 방법론 1–2개 중복 허용 — 합계 > 789.

## 1. 방법론 빈도 순위 (789편 전수)

| 순위 | 방법론 | 편수 | 비율 | 학술 수요 | NetMiner 지원 |
|------|--------|------|------|----------|---------------|
| **1** | **LLM / 생성형 AI 활용** (프롬프팅·파인튜닝·RAG·에이전트) | **~215** | **~27%** | 매우 높음, **가속 중** | ❌ 미지원 |
| **2** | **감성 분석** (사전·ML·트랜스포머·ABSA) | **~213** | **~27%** | 매우 높음, 안정적 | ⚠️ 부분 (Lab, 7개 언어) |
| **3** | **토픽 모델링** (LDA·BERTopic·STM·NMF·keyATM) | **~145** | **~18%** | 높음 | ✅ (LDA + BERTopic + BERTrend) |
| 4 | **텍스트 분류 / 트랜스포머 파인튜닝** (BERT 계열, SVM·RF 베이스라인 포함) | ~120 | ~15% | 높음 | ⚠️ 부분 (Classical ML만) |
| 5 | **진성 SNA / 네트워크 분석** | **~50–57** | **~7%** | 중간 | ✅ 핵심 강점 |
| 6 | **혼합·복합 방법론** (정성+정량, 다단계 파이프라인) | ~45 | ~6% | 중간 | ⚠️ 부분 |
| 7 | **GNN / 그래프 딥러닝** | ~25–30 | ~3–4% | 낮음(응용) | ✅ GCN/GraphSAGE/GAT |
| 8 | **멀티모달 융합** (텍스트+이미지/음성/영상) | ~25 | ~3% | 성장 중 | ❌ 미지원 |
| — | **저자원 언어 NLP** (교차 클러스터) | ~120–160 | **~15–20%** | 지속 확대 | ⚠️ 한/영/중만 |

### 1-1. LLM이 1위로 역전 — 그리고 가속 중

이전 592편 집계에서는 감성 분석(1위) > LLM(2위)이었으나, **789편 전수 기준으로 LLM이 근소하게 1위로 역전**했다. 더 중요한 것은 **청크 간 추세**다.

| 청크 | LLM 편수(추정) | 비고 |
|------|---------------|------|
| 청크 0 | ~20 | 분류·생성 중심 |
| 청크 1 | ~25 | LLM 에이전트·멀티에이전트 등장 |
| 청크 2 | ~15 | LLM-as-coder 검증 연구 |
| 청크 3 | ~40 | **최대 클러스터로 부상** |
| 청크 4 | ~45 | LLM-as-annotator가 전통 ML 대체 |
| 청크 5 | ~35 | 멀티에이전트 토론·LLM-as-judge |
| 청크 6 | ~35 | **zero-shot + RAG가 스탠스·감성·이벤트 추출의 "다수파 방법"으로 확립** |

2026년 게재 논문 비중이 높은 후반 청크(3~6)에서 LLM 비중이 뚜렷이 상승한다. 청크 6의 판정 — *"zero-shot 분류와 RAG 파이프라인이 이제 명백한 다수파 방법"* — 은 연도별 가속 신호로 읽어야 한다.

## 2. 청크 간 반복 확인된 핵심 발견

### 2-1. ⭐ 도메인 특화 소형 모델이 범용 LLM 프롬프팅을 이긴다 (7개 청크 중 4개 이상에서 독립 확인)

가장 근거가 탄탄한 교차 청크 발견이다. **도메인에 파인튜닝된 소형 모델이 정확도·비용·속도 세 축 모두에서 범용 LLM 프롬프팅을 반복적으로 능가**한다.

| 확인 모델 | 청크 | 도메인 |
|-----------|------|--------|
| ConfliBERT | 0, 4 | 분쟁·정치 이벤트 |
| DEBATE, DeBERTa | 0 | 담론·논증 |
| BERTimbau-LoRA | 4 | 포르투갈어 |
| RuBioBERT | 4 | 러시아어 의생명 |
| SVM + TF-IDF (전통 ML) | 3 | 터키어 법률 텍스트 — LLM zero-shot과 동률 또는 우위, 속도·비용은 압도 |

**제품 기획 시사점**: "LLM을 넣어야 최신"이라는 압박에 대한 학술적 반증. NetMiner가 지향해야 할 방향은 범용 LLM 탑재 경쟁이 아니라 **(a) 도메인 특화 경량 모델을 붙일 수 있는 연동 지점**, **(b) 전통 ML·네트워크 분석의 비용·재현성 강점 강조**다. 4B급 소형 모델 캐스케이드가 전체 LLM 호출 대비 토큰 96.9%를 절감했다는 사례(청크 4)가 이 논리를 뒷받침한다.

### 2-2. BERTopic > LDA는 이제 확립된 패턴

"LDA vs BERTopic 경주(horse race)" 자체가 하나의 하위 장르로 굳었다(청크 3). 결과는 거의 일관되게 BERTopic 우위 — **수치 코히런스가 LDA에 유리하게 나와도 의미적 해석 가능성에서 BERTopic이 이긴다**는 판정이 반복된다(청크 3). 2026년 대규모 토픽모델링 논문은 사실상 BERTopic 기본 채택(청크 6). NMF도 LDA 대비 코히런스 우위를 보이며(청크 0), 신규 프레임워크(SemaTopic·ARIA)가 BERTopic을 6.2% 추가 개선(청크 1).

→ 상세 및 **중요한 이전 인사이트 정정**: [[pages/methods/topic_modeling|토픽 모델링]]

### 2-3. 진성 SNA는 응용 분야의 소수파다 (~7%)

전수 판독으로 **실제 네트워크 데이터를 구성해 분석한 논문은 789편 중 약 50–57편(~7%)**에 불과했다.

| 청크 | 진성 SNA 편수 |
|------|--------------|
| 0 | 6 |
| 1 | 12 |
| 2 | 7 |
| 3 | 12 |
| 4 | 10 |
| 5 | **2–3 (114편 중!)** |
| 6 | 7 |
| **합계** | **~50–57 (~7%)** |

이는 유형 C 수집의 **목적에 부합하는 결과**다. 유형 C는 SNA 심화가 아니라 **응용 분야의 폭(breadth)과 신규 고객 세그먼트 발굴**을 위한 것이며, "social network"·"text analysis" 키워드로 수집된 논문 대다수는 텍스트 마이닝 계열이다. 동시에 **"SNA 태그가 붙은 페이지 대부분은 자동 인제스트 보일러플레이트"**라는 점이 청크 0·2·5에서 반복 확인되었다(SCHEMA 규칙 1 재확인).

### 2-4. GNN 태그 ≠ GNN 논문

GNN 태그가 붙은 ~25–30편 중 **실제 응용 데모는 극소수**다. 대부분 ML 방법론 논문·서베이이며, 청크 5의 "지식그래프/GNN 인접" 6편은 LLM으로 구축한 지식그래프일 뿐 GCN/GraphSAGE가 아니었다. 진성 사례는 VGAE 이상탐지(청크 0), PaSTO-GNN 에세이 채점·이중 오토인코더 동적 네트워크 이상탐지(청크 2), 다층 네트워크 GNN 링크 예측(청크 6, wang_mc) 정도.

## 3. 방법론별 세부 분포

### 3-1. LLM / 생성형 AI (~215편)

| 활용 패턴 | 비중 | 대표 사례 |
|-----------|------|----------|
| 주석·코딩 자동화 (LLM-as-annotator) | 최대 | 정성 코딩 도구 "Social Verbatim"·"Sandpiper" (청크 3) |
| 도메인 파인튜닝 (LoRA/QLoRA/PEFT) | 높음 | Llama-3.1-8B-LoRA, BERTimbau-LoRA, llama.cpp·Unsloth 온디바이스 |
| zero-shot 분류 + RAG | **급증** | 2026 스탠스·도덕가치·이벤트 추출의 다수파 (청크 6) |
| 벤치마킹·신뢰성 메타연구 | 성장 | "마법의 프롬프트는 없다" — 프롬프트 효과가 모델 간 일관되지 않음 (청크 4) |
| 멀티에이전트·LLM-as-judge | 성장 | 멀티에이전트 토론 프레임워크 (청크 5) |
| 편향·안전성 분류체계 | 중간 | "7×7×7" LLM 안전 taxonomy 논문군 (청크 3) |

→ 상세: [[pages/methods/llm_nlp|LLM / NLP 활용]]

### 3-2. 감성 분석 (~213편)

사전 기반(VADER/TextBlob/SentiStrength/InSet/LIWC) → 전통 ML(SVM/RF/NB/LR) → 트랜스포머(BERT/RoBERTa/FinBERT/IndoBERT/MentalBERT/AfroXLMR) → LLM ABSA 순으로 세대 이동이 진행 중이며, **네 세대가 동시에 공존**하는 것이 특징. 새로운 격차 두 가지:

- **ABSA-via-LLM이 토픽모델링을 대체**: LDA 단일 토픽 할당 시 **정보 손실 51.2%**, GPT 기반 ABSA가 현저히 우수(청크 3).
- **멀티모달 감성 융합**(텍스트+음성+영상)이 성장 클러스터(청크 3·6) — NetMiner 미지원 영역.

→ 상세: [[pages/methods/sentiment_analysis|감성 분석]]

### 3-3. 토픽 모델링 (~145편)

BERTopic(UMAP+HDBSCAN) 우위 확립. LDA는 베이스라인·비교군으로 잔존. STM은 사회과학 공변량 분석에서 유지. 신규: SemaTopic, ARIA, LLM-in-the-loop 토픽 정제(청크 4).

### 3-4. 진성 SNA 사례 (~50–57편) — 대표 사례

## 5. 요약: 10가지 트렌드 (789편 전수 기준)

1. **LLM이 방법론 1위로 역전, 그리고 가속 중** — 2026년 논문에서 zero-shot·RAG가 다수파 방법으로 확립.
2. **도메인 특화 소형 모델 > 범용 LLM 프롬프팅** — 4개 이상 독립 청크에서 확인된 최강 근거 발견.
3. **감성 분석은 여전히 초대형 클러스터(27%)** — 사전·ML·트랜스포머·LLM 네 세대 공존.
4. **BERTopic의 LDA 대체 완료 단계** — 단, 이 사용량은 **응용/텍스트마이닝 문헌**의 것이며 SNA 전문지와는 다르다(4장·토픽모델링 페이지 참조).
5. **진성 SNA는 응용 분야의 7%** — 유형 C의 역할은 폭 탐색이지 SNA 심화가 아님을 재확인.
6. **저자원 언어 NLP가 15–20%의 지속 교차 클러스터** — 아랍어·네팔어·카자흐어·방글라어·인니어·헝가리어·타직어·아프리카 언어(AfroXLMR).
7. **멀티모달 융합이 새 성장 축** — NetMiner 텍스트 전용 한계가 처음으로 구조적 격차로 부각.
8. **LLM이 연구 인프라를 넘어 "연구 대상 자체"로** — 문헌 리뷰 자동화, 피어리뷰 분석, "AI가 만드는 과학 단일문화" 비판 등 재귀적 메타 장르 형성(청크 6).
9. **LLM으로 네트워크 형성 이론을 실험** — papachrist_network_formation: 멀티 LLM 에이전트가 선호적 연결·삼각 폐쇄·동종선호를 재현. SNA 이론 연구의 신규 방향.
10. **경량·온디바이스 LLM 배포가 실무 트렌드** — QLoRA·Unsloth·llama.cpp·4B 캐스케이드(토큰 96.9% 절감).

## 6. 데이터 품질 이슈 (위키 운영)

- **모지바케 다수**: 청크 0에서 개별 페이지의 한국어 요약 섹션에 인코딩 깨짐이 다수 발견됨. 번역 파이프라인 인코딩 버그로 추정 — **콘텐츠 트렌드가 아닌 위키 데이터 품질 이슈**. `log.md`에 별도 기록 필요.
- **중복 논문 3건** 확인(청크 0에서 1건, 청크 1에서 2건 — 동일 연구의 복수 게재). 빈도 집계에서는 1편으로 처리(SCHEMA 규칙 4).
- **유형 분류 노이즈**: 청크 2에서 순수 이론·통계 네트워크 논문(확률블록모델 리뷰, Ising 여론동학, 혼합멤버십 추론, HMM 삼각폐쇄)이 applied/에 섞여 있음 — 유형 B가 적절.
