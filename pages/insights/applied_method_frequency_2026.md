## 2. 방법론별 세부 분류 (682편 기준)

### 2-1. 토픽 모델링 (~144편)

| 방법 | 편수 | 비고 |
|------|------|------|
| LDA (Latent Dirichlet Allocation) | ~80 | 1차(~55) + 신규(~25). 여전히 지배적 |
| BERTopic | ~34 | 1차(~18) + 신규(~16). 빠르게 성장 |
| STM (Structural Topic Model) | ~15 | 정치학·사회과학 선호. 신규에서 다수 등장 |
| keyATM (키워드 보조 토픽모델) | ~8 | R 패키지. 정책 문서·정치 담론에서 부상 |
| NMF (Non-negative Matrix Factorization) | ~7 | LDA 대안으로 비교 논문에서 등장 |
| 기타 (TopicGPT·BioVMNVTM 등) | ~5 | LLM 기반 신규 방법론 |

> **LDA vs BERTopic 경쟁 심화**: 682편 기준 LDA(~80) 우세 유지하나 BERTopic(~34)이 두 배 성장. "BERTopic vs LDA 비교" 논문이 건설안전·정책·마케팅·보건 등 다분야에서 등장 — BERTopic이 표준 대안으로 확립 단계.
> **STM 부상**: 신규 논문에서 STM이 특히 정치·사회과학 분야에서 반복 등장. 공변량(시간·지역·그룹)과의 결합이 강점.
> **keyATM 신흥 트렌드**: 미리 정의한 키워드로 토픽 방향을 제어하는 keyATM이 정책 분야(2025_park_disappeared_deleted_media, 2025_dai_conceptualizing 등)에서 확인.

### 2-2. 감성 분석 (~253편)

| 유형 | 편수 | 주요 도구 |
|------|------|----------|
| 딥러닝/트랜스포머 기반 | ~140 | BERT, RoBERTa, ELECTRA, IndoBERT, mBERT, FinBERT |
| 사전 기반 (Lexicon) | ~45 | VADER, TextBlob, SenticNet, NRCLex, InSet Lexicon |
| ML 기반 (SVM/NB/LR+TF-IDF) | ~40 | SVM+TF-IDF가 여전히 표준 베이스라인 |
| 앙상블/하이브리드 | ~28 | VADER+BERT, TF-IDF+SVM, 다방법 앙상블 |
| 측면 기반 (ABSA) | ~25 | SBERT+ABSA, aspect-level BERT, SVM+베이지안 최적화 |
| 감정 다중분류 (11개+ 감정) | ~12 | NRC Lexicon, Plutchik 기반, DeBERTa |

> **ABSA 급성장**: 측면 기반 감성 분석이 682편 기준 ~25편으로 379편 기준(~15편)에서 크게 증가. 마케팅(리뷰)·관광·e-커머스에서 "어떤 속성에서 어떤 감성?"을 묻는 분석이 표준화 중.
> **저자원 언어 급증**: 2025 신규 논문에서 인도네시아어·아랍어·방글라어·카자흐어·헝가리어 대상 감성 분석이 대거 등장 (~30편). 영어 중심 도구의 한계를 특화 모델(IndoBERT·AraBERT·IndoBERTweet)로 극복하는 흐름.

### 2-3. SNA / 네트워크 분석 (~75편)

| 세부 방법 | 편수 | 응용 맥락 |
|-----------|------|----------|
| 공출현 / 의미연결망 / 키워드 네트워크 | ~25 | 서지계량, 정책 담론, K-POP 연구 동향 |
| 중심성 분석 | ~18 | 소셜미디어 영향력, 재난위험 우선순위화 |
| 커뮤니티 탐지 (Louvain 등) | ~12 | 에코챔버, 이념 군집, 정치 양극화 |
| 복잡 네트워크 / 다층 네트워크 | ~8 | 농업 위험 이전, 미생물 모티프 네트워크 |
| 에고센트릭 네트워크 | ~5 | 농촌 디지털화, 난민 커뮤니티 |
| 정보 확산 / ABM | ~7 | 소셜미디어 양극화 시뮬레이션, SIR 모델 |

> **SNA 응용 도메인 확장**: 사회과학을 넘어 농업생태(미생물 네트워크), 재난안전(위험요인 공출현), 식량안보(TERGM 농업 네트워크), 교통(P2P 차량 속성 SNA) 등 비전통 분야로 확산.
> **NetMiner 실제 언급**: 2025_lee(한국 법률 담론 의미연결망+CONCOR)에서 NetMiner 추정 사용 확인. TEXTOM은 2026_yoo(K-POP 연구)에서 직접 언급.

### 2-4. LLM 활용 패턴 (~234편)

| 패턴 | 편수 | 대표 사례 |
|------|------|----------|
| 방법론 도구화 (주석·분류 자동화) | ~70 | 정치텍스트 자동코딩, 임상노트 추출 |
| 파인튜닝 (도메인 특화) | ~80 | 법률 BERT, 의료 GPT, ConfliBERT, FinBERT |
| 벤치마킹·비교 평가 | ~50 | 오픈소스 vs 상용 LLM 비교, 7개 언어 비교 |
| RAG (검색 증강 생성) | ~15 | 의료 RAG, 법률 GraphRAG, 건설안전 BifrostRAG |
| LoRA / PEFT (경량 파인튜닝) | ~10 | Llama-3.1 LoRA, QLoRA, 4-bit 양자화 |
| LLM 에이전트 시스템 | ~9 | 멀티에이전트 토론, 시뮬레이션, 오케스트레이션 |

> **RAG + 지식그래프 결합 부상**: 2025–2026 신규 논문에서 단순 RAG를 넘어 GraphRAG·BifrostRAG 등 구조화 지식그래프와 결합한 복합 RAG 아키텍처가 등장. 법률·안전·보안 도메인 집중.
> **LoRA 경량 파인튜닝 표준화**: 소비자급 GPU 환경에서 LLM 파인튜닝을 가능하게 하는 LoRA/PEFT가 다수 논문에서 채택. "오픈소스 LLM + LoRA"가 도메인 특화 모델의 새 표준으로 부상.
> **LLM 에이전트 사회과학 진입**: 소셜미디어 양극화 시뮬레이션(2025_boji), LLM 네트워크 형성 비교(2025_papachrist_network) 등 LLM 에이전트를 사회과학 실험 도구로 사용하는 초기 흐름 포착.

### 5-2. NetMiner로 커버 가능한 응용 논문 워크플로우

응용 분야에서 가장 많이 반복되는 **NetMiner 재현 가능 패턴**:

1. **키워드 공출현 네트워크**: 정책 문서·학술 문헌 키워드 → 공출현 행렬 → SNA 시각화 (ESG 담론, 서지계량 연구에서 다수 등장)

## 6. 방법론 트렌드 요약 (682편 기준)

1. **감성 분석의 압도적 주류화**: 682편 중 ~37%가 감성 분석 핵심 방법론. 2025년 신규 논문에서 46%를 차지해 성장세 확인. ABSA·다국어·감정 다중분류로 고도화 중.

2. **LLM의 연구 인프라化**: LLM이 "연구 주제"에서 "연구 도구"로 전환 완료. LoRA·PEFT로 경량 파인튜닝이 표준화. 오픈소스 LLM(Llama, Mistral)이 GPT와 경쟁하는 단계.

3. **BERTopic의 LDA 대체 가속**: LDA(~80) 우세하나 BERTopic(~34)이 두 배 성장. "BERTopic > LDA" 결론 내리는 비교 논문이 다분야에서 반복 등장.

4. **STM + keyATM: 사회과학 토픽모델링 양강 부상**: 공변량 통합 STM과 키워드 제어 keyATM이 정치·사회 분야에서 LDA 대안으로 자리잡는 중.

5. **RAG + 지식그래프 융합 등장**: 단순 RAG에서 GraphRAG·BifrostRAG 등 구조화 지식그래프와의 복합 아키텍처로 발전. 법률·의료·보안 도메인 중심.

6. **저자원 언어 NLP 급증**: 2025년 신규 논문에서 인도네시아어·아랍어·방글라어·카자흐어 등 비영어 연구가 전체의 20% 이상 차지. IndoBERT·AraBERT 등 언어 특화 모델 채택 표준화.

7. **텍스트 + 네트워크 복합 분석 심화**: 의미연결망+LDA, SNA+감성, 서지계량+공출현 네트워크가 거의 모든 분야에서 등장. NetMiner 핵심 강점과 직결.

8. **XAI 내재화 가속**: SHAP·LIME이 분석 파이프라인의 필수 구성요소로 정착. "왜" 설명하는 연구 문화 확산.

9. **LLM 에이전트 사회과학 진입**: 소셜미디어 양극화 시뮬레이션, 네트워크 형성 비교 실험 등 LLM 에이전트를 사회현상 모델링 도구로 사용하는 선행 연구 등장.

10. **NetMiner 실제 참조 확인**: 682편 중 2025_lee(한국 법률 담론)에서 NetMiner 추정 사용, 2026_yoo에서 TEXTOM 직접 언급. 한국어 텍스트 분석 시장에서 NetMiner/TEXTOM 경쟁 지속.
