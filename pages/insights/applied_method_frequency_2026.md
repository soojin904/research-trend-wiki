## 2. 방법론별 세부 분류

### 2-1. 토픽 모델링 (~84편)

| 방법 | 편수 | 비고 |
|------|------|------|
| LDA (Latent Dirichlet Allocation) | ~55 | 전통적 방법, 여전히 지배적 |
| BERTopic | ~18 | LDA 대비 빠르게 성장 중 |
| STM (Structural Topic Model) | ~6 | 정치학·사회과학 선호 |
| 기타 (LX Topic, TopicGPT, FASTopic) | ~5 | LLM 기반 신규 방법 |

> **LDA vs BERTopic 경쟁**: LDA 단독 사용이 감소하고 BERTopic 또는 "LDA+BERTopic 비교" 논문이 증가. 여러 청크에서 공통적으로 "BERTopic이 LDA를 대체하는 흐름" 관찰.

### 2-2. 감성 분석 (~140편)

| 유형 | 편수 | 주요 도구 |
|------|------|----------|
| 딥러닝/트랜스포머 기반 | ~80 | BERT, RoBERTa, ELECTRA, AraBERT, IndoBERT |
| 사전 기반 (Lexicon) | ~25 | VADER, TextBlob, SenticNet |
| 앙상블/하이브리드 | ~20 | VADER+BERT, TF-IDF+SVM |
| 측면 기반 (ABSA) | ~15 | BERTopic+ABSA, aspect-level BERT |

### 2-3. SNA / 네트워크 분석 (~45편)

| 세부 방법 | 편수 | 응용 맥락 |
|-----------|------|----------|
| 공출현 / 의미연결망 | ~18 | 키워드 네트워크, 서지계량, 정책 담론 |
| 중심성 분석 | ~12 | 소셜미디어 영향력, 조직 협업 |
| 커뮤니티 탐지 | ~8 | 에코챔버, 모듈성 분석, 클러스터링 |
| 정보 확산 모델 | ~5 | 허위정보 전파, 영향력 최대화 |
| 다층/ego 네트워크 | ~4 | 멀티플렉스 소셜 네트워크, 취업 탐색 |
| 종단/동적 네트워크 | ~3 | 협업 혁신 네트워크 진화, SAOM |

## 5. NetMiner 관점 시사점

### 5-1. 학술 수요 vs NetMiner 지원 여부

| 방법론 | 학술 수요 | NetMiner 지원 | 격차 / 기회 |
|--------|-----------|---------------|------------|
| LLM 파인튜닝·RAG | 매우 높음 (~150편, 40%) | ❌ | 연동 필요 없음 — 포지셔닝: "분석 후단" |
| 감성 분석 | 높음 (~115편, 30%) | ⚠️ 기본 | ABSA 기능 강화 필요 |
| 토픽 모델링 (LDA) | 높음 (~45편) | ✅ | 경쟁력 있음 |
| BERTopic | 성장 (~15편) | ❌ | 중기 도입 검토 |
| SNA + 텍스트 결합 | 중간 (~16편) | ✅ 강점 | 핵심 차별화 포인트 |
| GNN | 중간 (~19편) | ❌ | 신규 기능 개발 부담 |
| SEM | 낮음 (~15편) | ❌ | 우선순위 낮음 |
| 서지계량 + 네트워크 | 중간 (~15편) | ✅ 가능 | Scopus/WoS 연동 강조 |

### 5-2. NetMiner로 커버 가능한 응용 논문 워크플로우

응용 분야에서 가장 많이 반복되는 **NetMiner 재현 가능 패턴**:

1. **키워드 공출현 네트워크**: 정책 문서·학술 문헌 키워드 → 공출현 행렬 → SNA 시각화 (ESG 담론, 서지계량 연구에서 다수 등장)
2. **텍스트마이닝 + 토픽모델링**: 소셜미디어/리뷰 텍스트 → LDA 토픽 → 중심 키워드 네트워크
3. **의미연결망 분석**: 코퍼스 → 단어 공출현 → SNA 중심성 분석 (Textom 사용자 워크플로우와 동일)
4. **협력 네트워크 분석**: 공저 네트워크, 비영리 협력망, 기업 파트너십 네트워크

### 5-3. 경쟁 도구 포지셔닝

| 도구 | 강점 | 약점 |
|------|------|------|
| **NetMiner** | SNA + 텍스트마이닝 통합, GUI, 노코드 | LLM 미지원, BERTopic 없음 |
| **Python (scikit-learn + networkx)** | 유연성, LLM 연동 | 코딩 필요, 시각화 약함 |
| **Gephi / VOSviewer** | 네트워크 시각화 | 텍스트 분석 없음 |
| **Textom** | 한국어 특화, 의미연결망 | SNA 기능 제한 |
| **Orange Data Mining** | GUI, 시각적 파이프라인 | SNA 기능 약함 |

## 6. 방법론 트렌드 요약

1. **LLM의 방법론 도구화**: LLM이 "연구 주제"에서 "연구 인프라"로 전환. 기존 인간 코딩을 대체하는 사례 급증.

2. **BERTopic의 LDA 잠식**: 아직 LDA가 우세하나(55 vs 18편), BERTopic+LDA 비교 논문 다수 — BERTopic이 점차 표준 대안으로 인정받는 중.

3. **텍스트 + 네트워크 복합 분석 표준화**: 단독 텍스트 분석에서 벗어나 결과를 네트워크 구조로 연결하는 복합 설계가 주류. NetMiner의 핵심 강점과 일치.

4. **감성 분석의 도메인 확산**: 마케팅·소셜미디어 중심에서 농업·법률·임상·ESG까지 확대. 도메인 특화 모델(AraBERT, IndoBERT 등) 채택 동반.

5. **저자원 언어 NLP 확산**: 아랍어, 인도네시아어, 베트남어 등 비영어권 NLP 연구가 전체의 15~20%를 차지. 다국어 텍스트 분석 수요 증가 확인.

6. **설명 가능 AI (XAI) 내재화**: SHAP·LIME을 분석 파이프라인에 포함하는 논문이 증가. "성능"보다 "왜"를 요구하는 연구 문화 확산.
