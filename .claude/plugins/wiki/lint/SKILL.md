위키 전체를 점검해 건강 상태를 유지한다.

## 인수
`/wiki:lint` (인수 없음)
`/wiki:lint --fix` (발견된 문제를 즉시 수정)

## 절차

### 1. 페이지 목록 수집
`D:\soojin\wiki\pages\` 하위 전체 .md 파일 목록 수집

### 2. 고아 페이지 탐지 (Orphan pages)
- 각 페이지로 향하는 위키링크(`[[...]]`)가 0개인 페이지 탐지
- index.md의 링크는 제외하고 판단
- `--fix`: 관련 페이지에 링크 추가 또는 index.md에서 제거 여부 제안

### 3. 깨진 위키링크 탐지
- `[[링크]]`가 가리키는 파일이 존재하지 않는 경우
- `--fix`: 파일 생성 또는 링크 수정

### 4. 최소 링크 미달 페이지
- 위키링크가 2개 미만인 페이지 목록
- `--fix`: 관련 개념 링크 추가

### 5. index.md 누락 페이지
- `pages/`에 존재하지만 `index.md`에 없는 페이지
- `--fix`: index.md에 자동 추가

### 6. overview.md 최신성 점검
- log.md의 최근 ingest 날짜와 overview.md 업데이트 날짜 비교
- 차이가 크면 갱신 권고

### 7. 중요 개념 페이지 누락 점검
- 페이지 본문에서 `[[링크]]`로 자주 참조되지만 페이지가 없는 개념 탐지
- 생성 권고 목록 제시

### 8. 보고서 출력
```
## 위키 건강 보고서 [YYYY-MM-DD]

### 요약
- 총 페이지: N
- 고아 페이지: N개
- 깨진 링크: N개
- 링크 부족 페이지: N개
- index.md 누락: N개

### 고아 페이지
- [[경로]] — 권고 조치

### 깨진 링크
- 파일: 링크 내용 → 권고 조치

### 생성 권고 페이지
- 개념명 — 참조 횟수 N회

### 권고 사항
1. ...
```

### 9. log.md 기록
```
## [YYYY-MM-DD] lint | 점검 결과 요약
- 고아: N, 깨진링크: N, 생성권고: N
```
