위키를 검색해 질문에 답하고, 가치 있는 답변을 위키에 저장한다.

## 인수
`/wiki:query <질문>`

예시:
- `/wiki:query NetMiner와 Gephi의 차이는?`
- `/wiki:query 복합 방법론에서 토픽모델링을 어떻게 결합하나?`
- `/wiki:query 2022년 이후 SNA 응용 논문 정리해줘`

## 절차

### 1. index.md 읽기
- 전체 페이지 목록과 태그 파악
- 질문과 관련된 페이지 후보 선별

### 2. 관련 페이지 읽기
- 후보 페이지를 우선순위대로 읽기
- 필요 시 overview.md 참조

### 3. 답변 합성
- 읽은 페이지를 바탕으로 답변 작성
- 인용: `([[페이지경로|출처]])` 형식으로 근거 명시
- 위키에 없는 내용은 "위키에 없음 — 추가 조사 필요"로 표시

### 4. 저장 여부 판단
다음 중 하나에 해당하면 새 페이지로 저장할 것을 제안:
- 새로운 비교·분석 (도구 비교, 방법론 비교 등)
- 여러 논문을 종합한 인사이트
- 반복 참조될 가능성이 높은 내용

저장 시: `pages/` 적절한 카테고리에 생성 후 `index.md` 업데이트, `log.md` 기록
```
## [YYYY-MM-DD] query | 질문 요약
- 참조 페이지: N개
- 신규 저장 페이지: 파일명 (없으면 생략)
```

## 답변 형식
질문 유형에 따라 형식 선택:
- 개념 설명 → 마크다운 텍스트
- 비교 → 표
- 논문 목록 → 표 또는 불릿
- 방법론 흐름 → 순서 있는 목록
